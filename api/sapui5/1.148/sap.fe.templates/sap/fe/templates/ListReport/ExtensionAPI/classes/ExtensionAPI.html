Class: ExtensionAPI

import ExtensionAPI from "sap/fe/templates/ListReport/ExtensionAPI";

Extension API for list reports in SAP Fiori elements for OData V4. To correctly integrate your app extension coding with SAP Fiori elements, use only the extensionAPI of SAP Fiori elements. Don't access or manipulate controls, properties, models, or other internal objects created by the SAP Fiori elements framework.

refresh()

refresh(): Promise<void>

Refreshes the List Report. This method currently only supports triggering the search (by clicking on the GO button) in the List Report Filter Bar. It can be used to request the initial load or to refresh the currently shown data based on the filters entered by the user. Please note: The Promise is resolved once the search is triggered and not once the data is returned.

Returns

Promise<void>

Resolved once the data is refreshed or rejected if the request failed
