Class: AddBookmarkButton

import AddBookmarkButton from "sap/ushell/ui/footerbar/AddBookmarkButton";

Enables users to save bookmark tiles in the Fiori launchpad. Clicking the button opens a dialog box for saving the app state, so that the app can be launched directly in that state from the launchpad.

Deprecated

As of version 1.136. Use sap.ushell.ui.BookmarkDialog instead.
