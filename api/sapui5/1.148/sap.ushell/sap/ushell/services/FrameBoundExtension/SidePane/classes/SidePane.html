Class: SidePane

import SidePane from "sap/ushell/services/FrameBoundExtension/SidePane";

The side pane extension point is positioned next the launchpad content. To be instantiated by sap.ushell.services.FrameBoundExtension.

Restriction: Does not work when called from within a iframe. The calling function has to be in the 'same frame' as the launchpad itself.

Since

1.124.0

createItem()

createItem(controlProperties, parameters?): Promise<Item>

Creates an item in the side pane.

The controlType can be any control and is by default a sap.m.Button. The controlProperties are passed to the constructor of the control.
