Interface: $ShapeSettings

import { $ShapeSettings } from "sap/gantt/config/Shape";

Describes the settings that can be provided to the Shape constructor.

Specifies whether or not should the shape be considered into bird eye range. we suggest to set this property to true only for shapes that really need to be considered into bird eye range.

optional groupAggregation?: PropertyBindingInfo | `{${string}}` | object[]

Aggregation shapes for sap.gantt.shape.Group class. This aggregation is only valid for shape classes with tag='g'. We recommend that you set the type of this argument to sap.gantt.config.Shape[]. Otherwise some properties you set may not function properly.

key?

optional key?: string | PropertyBindingInfo

Primary key of the shape configuration. This property can be referenced from other configuration object, such as sap.gantt.config.ChartScheme. This property is only relevant to top Shape configuration.

level?

optional level?: string | PropertyBindingInfo

Level of shapes. Shapes closer to the top shape have a smaller value in level. This property is only relevant to top shape configuration (non aggregated shape configuration).

modeKeys?

optional modeKeys?: string[] | PropertyBindingInfo | `{${string}}`

Specifies the key of modes in which the shape is drawn. If you leave this property empty, the shape is drawn in all modes.

resizeShadowClassName?

optional resizeShadowClassName?: string | PropertyBindingInfo

Aggregation class for drawing shadow when resizing this shape. If nothing is assigned to this property, sap.gantt.Gantt instantiates the default shadow shape class.

selectedClassName?

optional selectedClassName?: string | PropertyBindingInfo

Aggregation class for drawing selection of this shape. If nothing is assigned to this property, sap.gantt.Gantt instantiates the default selected shape class.

shapeClassName?

optional shapeClassName?: string | PropertyBindingInfo

Specifies the shape class to be used for data representation. Both shapes from sap.gantt.shape and extended shapes can be used here.

shapeDataName?

shapeProperties?

optional shapeProperties?: object | PropertyBindingInfo | `{${string}}`

Pre-configured values for Shape. The values specified in this object have a higher priority than values coded in the Shape class.

switchOfCheckBox?
