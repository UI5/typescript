Class: WeekPattern

import WeekPattern from "sap/gantt/skipTime/WeekPattern";

Enables the user to define weekly skip pattern. Non working hours are to be removed for timeLineOptions with innerInterval unit as sap.gantt.config.TimeUnit.day, sap.gantt.config.TimeUnit.hour and sap.gantt.config.TimeUnit.minute
