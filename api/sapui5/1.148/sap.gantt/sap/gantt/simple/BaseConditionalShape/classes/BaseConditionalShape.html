Class: BaseConditionalShape

import BaseConditionalShape from "sap/gantt/simple/BaseConditionalShape";

A conditional shape renders one of the sap.gantt.simple.BaseShape shapes assigned to it using the activeShape property. This allows you to switch between shapes based on properties from data binding.

setCountInBirdEye()

setCountInBirdEye(bCountInBirdEye?): this

Sets a new value for property #getCountInBirdEye countInBirdEye.

Specifies whether or not the system takes this shape into account at the bird's eye zoom level. We suggest that you set this property to true only for shapes that really need to be considered when in the bird's eye view.

This property is overwritten by property countInBirdEye of the activeShape shape from the shapes aggregation. For setting this property, use the setter method of the active shape. The getter method returns the property value of the active shape.

When called with a value of null or undefined, the default value of the property will be restored.

Default value is false.
