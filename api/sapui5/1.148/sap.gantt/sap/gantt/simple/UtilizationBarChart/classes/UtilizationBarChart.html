Class: UtilizationBarChart

import UtilizationBarChart from "sap/gantt/simple/UtilizationBarChart";

Utilization Bar Chart (UBC) is a complex shape, you can use it to visualize a resource the capacity and actual consumption of a resource. There is a line in UBC to visualize the actual capacity consumption, you can change the line color by property stroke
