Class: LegendShapeGroup

import LegendShapeGroup from "sap/gantt/simple/LegendShapeGroup";

Legend Shape Group class for accommodating multiple shapes in ListLegendItem. Only following shapes are allowed: BaseRectangle, BaseDiamod, BaseChevron, BaseCursor, BaseLine, BasePath and BaseImage.
