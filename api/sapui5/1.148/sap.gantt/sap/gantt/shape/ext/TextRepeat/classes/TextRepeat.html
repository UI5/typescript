Class: TextRepeat

import TextRepeat from "sap/gantt/shape/ext/TextRepeat";

A TextRepeat definition shape is used to define graphic objects which can be replicated ("tiled") at fixed intervals in the x and y axes to cover the areas to be painted. The text patterns are defined using a 'pattern' element and then referenced by the 'fill' and 'stroke' properties on a given graphics element to indicate that the element will be filled or stroked with the referenced pattern.

Deprecated

As of version 1.64. the concept has been discarded.
