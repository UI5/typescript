Class: Group

import Group from "sap/gantt/shape/Group";

Group shape class using SVG tag 'group'. It is a container shape. Any other shapes can be aggregated under a group.

Deprecated

As of version 1.64. replaced by sap.gantt.simple.BaseGroup.
