name

name: { plural: string | Function; singular: string | Function; } | Function

Specify or calculate a speaking name for the control (which is understandable to key users). This is needed for the "reveal" action to show the names in the context menu (Add and Available ). Name your control based on the general UI concept and follow the guidance from https://experience.sap.com/fiori-design/. Example: Key users don't care about the difference between a smart, mobile or responsive version of a form, it's just a form.
