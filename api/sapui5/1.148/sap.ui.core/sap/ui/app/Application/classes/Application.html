Abstract Class: Application

import Application from "sap/ui/app/Application";

Experimental

Abstract application class. Extend this class to create a central application class.

Deprecated

As of version 1.15.1. The Component class is enhanced to take care about the Application code. As of version 1.11.1. The Application class is still under construction, so some implementation details can be changed in future.
