Type Alias: Association

import { Association } from "sap/ui/base/ManagedObject/namespaces/MetadataOptions";

Association = object

An object literal describing an association of a class derived from sap.ui.base.ManagedObject. See sap.ui.base.ManagedObject.MetadataOptions MetadataOptions for details on its usage.

Properties

deprecated?

optional deprecated?: boolean

Flag that marks the association as deprecated (defaults to false). May lead to an additional warning log message at runtime when the association is still used. For the documentation, also add a @deprecated tag in the JSDoc, describing since when it is deprecated and what any alternatives are.

multiple?

optional multiple?: boolean

Whether the association is a 0..1 (false) or a 0..n association (true), defaults to false (0..1) for associations

singularName?

optional singularName?: string

Custom singular name. This is only relevant for 0..n associations where the association name should be defined in plural form and the framework tries to generate the singular form of it for certain places where it is needed. To do so, the framework knows a set of common rules for building the plural form of English nouns and uses these rules to determine a singular name on its own. If that name is wrong, a singularName can be specified with this property. E.g. for an association named items, methods affecting multiple objects in an association will use the plural name (getItems()), whereas methods that deal with a single object will automatically use the generated singular name (e.g. addItem(...)). However, the generated singular form for an association news would be new, which is wrong, so the singular name "news" would need to be set.

type?

optional type?: string

Type of the new association

visibility?

optional visibility?: "hidden" | "public"

Either 'hidden' or 'public', defaults to 'public'. Associations that belong to the API of a class must be 'public' whereas 'hidden' associations can only be used internally. Only public associations are accepted by the constructor or by applySettings or in declarative representations like an XMLView. Equally, only public associations are cloned.
