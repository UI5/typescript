attachMessageChange(oData, fnFunction, oListener?): this

Attaches event handler fnFunction to the #event:messageChange messageChange event of this sap.ui.core.message.MessageProcessor.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.ui.core.message.MessageProcessor itself.
