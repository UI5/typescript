MetadataOptions = MetadataOptions & object

The structure of the "metadata" object which is passed when inheriting from sap.ui.core.Component using its static "extend" method. See sap.ui.core.Component.extend and sap.ui.core.Component.create for additional details on its usage.

Type Declaration

manifest?

optional manifest?: false | object | "json"

The manifest option determines how a component manifest should be evaluated. Default is undefined.

When set to false or undefined, no manifest.json is present for this Component, however the Component can still be started with a manifest given as an argument of the factory function, see sap.ui.core.Component.create. When set to an object, this object will be interpreted as a manifest and must adhere to the descriptor schema for components. When set to the string literal "json", this property indicates that the component configuration should be read from a manifest.json file which is assumed to exist next to the Component.js file.
