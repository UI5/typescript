Type Alias: RoutingMetadata

import { RoutingMetadata } from "sap/ui/core/UIComponent";

RoutingMetadata = object

An object containing the routing-relevant configurations, routes, targets, config.

Example for a config::


    routing: {
        "routes": [
            {
                "name": "welcome",
                // If the URL has no hash e.g.: index.html or index.html# , this route will be matched.
                "pattern": "",
                // Displays the target called "welcome" specified in metadata.routing.targets.welcome.
                "target": "welcome"
            },
            {
                "name": "product",
                "pattern": "Product/{id}",
                "target": "product"
            }
        ],
        // Default values for targets
        "config": {
            // For a detailed documentation of these parameters have a look at the sap.ui.core.routing.Targets documentation
            "viewType": "XML",
            "controlId": "App",
            "controlAggregation": "pages",
            "viewNamespace": "myApplication.namespace",
            // If you are using the mobile library, you have to use an sap.m.routing.Router, to get support for
            // the controls sap.m.App, sap.m.SplitApp, sap.m.NavContainer and sap.m.SplitContainer.
            "routerClass": "sap.m.routing.Router",
            // What happens if no route matches the hash?
            "bypassed": {
                // the not found target gets displayed
                "target": "notFound"
            }
        },
        "targets": {
            "welcome": {
                // Referenced by the route "welcome"
                "viewName": "Welcome",
                "viewLevel": 0
            },
            "product": {
                // Referenced by the route "Product"
                "viewName": "Product",
                "viewLevel": 1
            },
            "notFound": {
                // Referenced by the bypassed section of the config
                "viewName": "NotFound"
            }
        }
    }

Properties

config?

optional config?: object

Since 1.16. An object containing default values used for routes and targets. See sap.ui.core.routing.Router#constructor and sap.ui.core.routing.Targets for more documentation.

rootView?

optional rootView?: string

By default, the root view will be set to the ID of the view returned by the sap.ui.core.UIComponent#getRootView function. You should not set this parameter if you create a view with the UIComponent.

routerClass?

optional routerClass?: string | Function

Since 1.20. The qualified name (in dot notation) or the constructor of the router class that should be used for the component's router. If you are using an own router extension, it has to be required before the constructor of the component is invoked. If you use sap.m.routing.Router, the component will automatically create an sap.m.routing.Targets instance. If you pass a function, it has to be the constructor of a class that extends a router.

targetsClass?

optional targetsClass?: string | Function

Since 1.28.1. The qualified name (in dot notation) or the constructor of the Targets class that should be used by the component's router. If you are using an own Targets extension, it has to be required before the constructor of the component is invoked. If you define routes in your routing section, this parameter will be ignored and the Targets instance of the router will be taken, see sap.ui.core.routing.Router#getTargets.

routes?

optional routes?: $RouteSettings[] | Record<string, $RouteSettings>

An array containing the routes that should be added to the router. See sap.ui.core.routing.Route for the allowed properties.
