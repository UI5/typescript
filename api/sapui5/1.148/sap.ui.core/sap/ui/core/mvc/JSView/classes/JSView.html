createContent()

createContent(): Control | Control[]

A method to be implemented by JSViews, returning the view UI.

While for declarative view types like XMLView or JSONView the user interface definition is declared in a separate file, JSViews programmatically constructs the UI. This happens in the createContent method which every JSView needs to implement. The view implementation can construct the complete UI in this method, or only return the root control and create the remainder of the UI lazily later on.

Returns

Control | Control[]

A control or array of controls representing the view user interface
