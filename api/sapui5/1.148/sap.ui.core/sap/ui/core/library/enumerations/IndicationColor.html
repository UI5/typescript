Enumeration: IndicationColor

Colors to highlight certain UI elements.

In contrast to the ValueState, the semantic meaning must be defined by the application.

This enum is part of the 'sap/ui/core/library' module export and must be accessed by the property 'IndicationColor'. See: fiori:/how-to-use-semantic-colors/ Semantic Colors
