Class: Dimension

import Dimension from "sap/chart/data/Dimension";

Definition of a single dimension in a chart

chartType binding rules pie, donut All dimensions are assigned to feed uid “color”. scatter, bubble All dimensions with role category are assigned to feed uid “shape”. heatmap All dimensions with role “series” and “category2” are assigned to the feed uid “categoryAxis2”. treemap All dimensions are assigned to the feed uid “categoryAxis” in the default sequence.

getRole()

getRole(): string

Gets current value of property #getRole role.

How the Dimension will influence the chart layout. Possible values are sap.chart.data.DimensionRoleType category, sap.chart.data.DimensionRoleType series or sap.chart.data.DimensionRoleType category2. The default is sap.chart.data.DimensionRoleType category.

You can create a new dimension as follow:


...
new sap.chart.data.Dimension({name: "DIMENSION1", role: sap.chart.data.DimensionRoleType.category})
...

Detailed usage of dimension role. Please refer to sap.chart.data.DimensionRoleType DimensionRoleType

NOTE: Has no effect if the Dimension is used as inResultDimensions by Chart

Default value is "category".

string

Value of property role
