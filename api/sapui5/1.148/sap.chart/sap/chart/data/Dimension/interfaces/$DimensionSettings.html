role?

optional role?: string | PropertyBindingInfo

How the Dimension will influence the chart layout. Possible values are sap.chart.data.DimensionRoleType category, sap.chart.data.DimensionRoleType series or sap.chart.data.DimensionRoleType category2. The default is sap.chart.data.DimensionRoleType category.

You can create a new dimension as follow:


...
new sap.chart.data.Dimension({name: "DIMENSION1", role: sap.chart.data.DimensionRoleType.category})
...

Detailed usage of dimension role. Please refer to sap.chart.data.DimensionRoleType DimensionRoleType

NOTE: Has no effect if the Dimension is used as inResultDimensions by Chart
