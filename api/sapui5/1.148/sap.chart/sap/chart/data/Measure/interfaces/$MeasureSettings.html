role?

optional role?: string | PropertyBindingInfo

How values of Measure will be rendered in the chart. Possible role values are sap.chart.data.MeasureRoleType axis1, sap.chart.data.MeasureRoleType axis2, sap.chart.data.MeasureRoleType axis3, and sap.chart.data.MeasureRoleType axis4. The default is sap.chart.data.MeasureRoleType axis1. They correspond to the well-known concepts of axis identifiers in the Cartesian coordinate system, e.g. a Y-axis in a bar/column/line chart, an X- and a Y-axis in a scatter chart, or two Y-axes in bar charts, and an optional third axis for the weight/size/intensity/temperature of a data point.

You can create a new measure as follow:


...
new sap.chart.data.Measure({name: "MEASURE1", role: sap.chart.data.MeasureRoleType.axis1})
...

Detailed usage of measure role. Please refer to sap.chart.data.MeasureRoleType MeasureRoleType

NOTE: Role definition would not work for Bullet Chart and users need to set semantics instead.

Semantically related measures for a measure with semantics "actual" value. It is an object with two properties:

 - "projectedValueMeasure" identifing the projected value measure, and
 - "referenceValueMeasure" identifing the reference value measure.

semantics?

optional semantics?: PropertyBindingInfo | `{${string}}` | MeasureSemantics

The semantics of the measure.

NOTE: Dimension-based coloring (see sap.chart.Chart#setColorings) does not work when semantics is set to sap.chart.data.MeasureSemantics.Projected or sap.chart.data.MeasureSemantics.Reference for visible measure(s).

NOTE: In Bullet chart measure defined as "Reference" maps to targetValues and "Projected" maps to additionalValues. Measures without definition will be recognized as actualValues.

unitBinding?

optional unitBinding?: string | PropertyBindingInfo

Unit for the measure, a pointer using the binding syntax to some field containing the unit. Value of the given field from the same data record will be displayed after formatted measure value in data label, tooltip and chart popover. NOTE: To work properly, the unit field must be set as visible dimension in chart, and only one unit value exists for any visible dimension value combination.
