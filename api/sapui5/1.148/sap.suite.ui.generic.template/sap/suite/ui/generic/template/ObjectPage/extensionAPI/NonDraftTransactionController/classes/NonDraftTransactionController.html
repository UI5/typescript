attachAfterSave()

attachAfterSave(fnFunction): void

Attach a handler to the save event

Parameters

fnFunction

Function

the handler function This function will receive an object which contains two properties: saveEntityPromise and sideEffectsExecutedPromise which both point to Promises. Both Promises will be rejected in case the save operation fails in the backend. Otherwise both Promises will be resolved, but at different point in time. The saveEntityPromise will be resolved immediately when the save operation has finished successfully. The sideEffectsExecutedPromise will be resolved as soon as the processing of all side-effects connected to this action has finished as well. Note that even a side-effect execution which results in an error would be considered as finished processing here.
