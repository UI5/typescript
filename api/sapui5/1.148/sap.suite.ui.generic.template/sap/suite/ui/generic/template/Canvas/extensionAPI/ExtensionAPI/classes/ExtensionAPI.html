securedExecution()

securedExecution(fnFunction, mParameters?): Promise<any>

Secured execution of the given function. Ensures that the function is only executed when certain conditions are fulfilled. See: Using the SecuredExecutionMethod

Parameters

fnFunction

Function

The function to be executed. Should return a promise that is settled after completion of the execution. If nothing is returned, immediate completion is assumed.

mParameters?

Parameters to define the preconditions to be checked before execution

busy?

{ check?: boolean; set?: boolean; }

Parameters regarding busy indication

busy.check?

boolean

Checks whether the application is currently busy. Function is only executed if not. Has to be set to false, if function is not triggered by direct user interaction, but as result of another function, that set the application busy.

busy.set?

boolean

Triggers a busy indication during function execution. Can be set to false in case of immediate completion.

dataloss?

{ navigation?: boolean; popup?: boolean; }

Parameters regarding dataloss prevention

dataloss.navigation?

boolean

Indicates that execution of the function leads to a navigation, i.e. leaves the current page, which induces a slightly different text for the dataloss popup.

dataloss.popup?

boolean

Provides a dataloss popup before execution of the function if needed (i.e. in non-draft case when model or registered methods contain pending changes).

mConsiderObjectsAsDeleted?

Record<string, any>

Tells the framework that objects will be deleted by fnFunction. Use the BindingContextPath as a key for the map. Fill the map with a Promise for each object which is to be deleted. The Promise must resolve after the deletion of the corresponding object or reject if the deletion is not successful.

sActionLabel?

string

In case of custom actions, the title of the message popup is set to sActionLabel.

Returns

Promise<any>

A Promise that is rejected, if execution is prohibited, and settled equivalent to the one returned by fnFunction.
