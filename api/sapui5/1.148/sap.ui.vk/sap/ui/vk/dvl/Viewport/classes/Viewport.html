Class: Viewport

import Viewport from "sap/ui/vk/dvl/Viewport";

Provides a rendering canvas for the 3D elements of a loaded scene.

Deprecated

As of version 1.72.0. DVL namespace will be removed in future. Use sap.ui.vk.Viewport instead.

getViewInfo()

getViewInfo(query?): object

Retrieves information about the current camera view in the scene, and saves the information in a JSON-like object. The information can then be used at a later time to restore the scene to the same camera view using the sap.ui.vk.Viewport#setViewInfo setViewInfo method.

Parameters

query?

Query object which indicates what information to be retrieved.

animation?

boolean

Indicator to retrieve animation information.

camera?

boolean | { matrices?: boolean; useTransitionCamera?: boolean; }

Indicator to retrieve camera information.

visibility?

boolean | { mode?: any; }

Indicator to retrieve visibility information.

Returns

object

JSON-like object which holds the current view information. See sap.ui.vk.Viewport#setViewInfo setViewInfo. In addition to properties defined in sap.ui.vk.Viewport#setViewInfo setViewInfo the output from sap.ui.vk.Viewport#getViewInfo getViewInfo contains camera view and projection matrices


  {
    ...
    camera: {
      ...
      matrices: {
        view:       [number, ...],
        projection: [number, ...],
      }
      ...
    },
    ...
  }

setViewInfo()

setViewInfo(viewInfo, flyToDuration?): this

Sets the current scene to use the camera view information acquired from the sap.ui.vk.Viewport#getViewInfo getViewInfo method. Internally, the setViewInfo method activates certain steps at certain animation times, and then changes the camera position, rotation and field of view (FOV) / zoom factor.

Parameters

viewInfo

A JSON-like object containing view information acquired using the sap.ui.vk.Viewport#getViewInfo getViewInfo method.

animation?

{ animationTime?: number; procedureIndex?: number; stepIndex?: number; stepVeId?: string; }

A JSON-like object containing the animation information.

animation.animationTime?

number

Time at which to activate the step.

animation.procedureIndex?

number

Procedure index in the list of procedures.

animation.stepIndex?

number

Step index in the list of steps in the procedure.

animation.stepVeId?

string

Step VE ID. If it is omitted then procedure and step indices are used.

camera?

{ bindingType: CameraFOVBindingType; fieldOfView: number; position: { x: number; y: number; z: number; }; projectionType: CameraProjectionType; rotation: { pitch: number; roll: number; yaw: number; }; zoomFactor: number; }

A JSON-like object containing the camera information.

camera.bindingType

CameraFOVBindingType

Camera field of view binding type.

camera.fieldOfView

number

Camera field of view in degrees. Applicable only to perspective cameras.

camera.position

{ x: number; y: number; z: number; }

Position defined in 3-dimensional space.

camera.position.x

number

X coordinate.

camera.position.y

number

Y coordinate.

camera.position.z

number

Z coordinate.

camera.projectionType

CameraProjectionType

Camera projection type.

camera.rotation

{ pitch: number; roll: number; yaw: number; }

Rotation defined in Aircraft principal axes.

camera.rotation.pitch

number

Angle around the lateral axis in degrees.

camera.rotation.roll

number

Angle around the longitudinal axis in degrees.

camera.rotation.yaw

number

Angle around the vertical axis in degrees.

camera.zoomFactor

number

Camera zoom factor. Applicable only to orthographic cameras.

visibility?

{ changes: string[]; hidden: string[]; mode: any; visible: string[]; }

A JSON-like object containing the visibility information.

visibility.changes

string[]

List of Ids of nodes with inverted visibility.

visibility.hidden

string[]

List of Ids of hidden nodes.

visibility.mode

any

If the mode equals to sap.ui.vk.VisibilityMode.Complete complete then the visible and hidden fields are defined. If the mode equals sap.ui.vk.VisibilityMode.Differences differences then the changes field is defined.
