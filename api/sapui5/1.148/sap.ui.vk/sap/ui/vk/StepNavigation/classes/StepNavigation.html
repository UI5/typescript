Class: StepNavigation

import StepNavigation from "sap/ui/vk/StepNavigation";

Enables capabilities for navigating and activating procedures and steps contained in a single 3D scene.

Since

1.32.0

Deprecated

As of version 1.72.0. This class is used only with DVL namespace which will be removed in future. Use sap.ui.vk.ViewGallery instead.
