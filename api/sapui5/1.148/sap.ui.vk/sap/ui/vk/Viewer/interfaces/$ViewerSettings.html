webGLContextAttributes?

optional webGLContextAttributes?: object | PropertyBindingInfo | `{${string}}`

Optional WebGL context attributes. A JSON object with the following boolean properties: - antialias {boolean} default value true. If set to true, the context will attempt to perform antialiased rendering if possible. - alpha {boolean} default value true. If set to true, the context will have an alpha (transparency) channel. - premultipliedAlpha {boolean} default value false. If set to true, the color channels in the framebuffer will be stored premultiplied by the alpha channel to improve performance. Other WebGL context attributes are also supported. WebGL context attributes cannot be changed after the control is fully initialized.
