Class: BarcodeScannerButton

import BarcodeScannerButton from "sap/ndc/BarcodeScannerButton";

A button control (displaying a barcode icon) to start the barcode scanning process. If the native scanning feature is not available or camera capability is not granted, the button is either hidden or it provides a fallback by opening a dialog with an input field where the barcode can be entered manually.
