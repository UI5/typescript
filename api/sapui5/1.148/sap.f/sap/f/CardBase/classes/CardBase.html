attachPress()

Call Signature

attachPress(oData, fnFunction, oListener?): this

Experimental

Attaches event handler fnFunction to the #event:press press event of this sap.f.CardBase.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.f.CardBase itself.

Fired when action is added on card level. Note*: Can be used only if semanticRole is sap.f.cards.SemanticRole.ListItem or the control is placed inside a sap.f.GridContainer.

As of version 1.131.
