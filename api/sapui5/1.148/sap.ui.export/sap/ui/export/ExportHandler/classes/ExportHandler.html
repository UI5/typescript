Class: ExportHandler

import ExportHandler from "sap/ui/export/ExportHandler";

The sap.ui.export.ExportHandler class allows you to export table data from an SAPUI5 application.

Call Signature

attachBeforeExport(oData, fnHandler, oListener?): this

Attaches event handler fnFunction to the sap.ui.export.ExportHandler#event:beforeExport event of this sap.ui.export.ExportHandler. When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.ui.export.ExportHandler itself. This event is fired just before the export process is started.
