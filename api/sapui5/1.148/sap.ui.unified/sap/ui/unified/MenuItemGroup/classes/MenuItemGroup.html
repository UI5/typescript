Class: MenuItemGroup

import MenuItemGroup from "sap/ui/unified/MenuItemGroup";

Group item to be used inside a menu. A menu items group represents a collection of menu items that can have the same selection mode (e.g. sap.ui.core.ItemSelectionMode.None, sap.ui.core.ItemSelectionMode.SingleSelect, or sap.ui.unified.ItemSelectionMode.MultiSelect).
