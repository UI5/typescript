Type Alias: FilterDelegateObject

import { FilterDelegateObject } from "sap/ui/mdc/library";

FilterDelegateObject = object

Acts a subset of the FilterBarDelegate that can be used in module:sap/ui/mdc/TableDelegate.getFilterDelegate TableDelegate.getFilterDelegate or module:sap/ui/mdc/ChartDelegate.getFilterDelegate Chart.getFilterDelegate to enable inbuilt filtering.

It provides basic filter functionality, including - Adding filter fields - Adding conditions - Removing conditions - Determining the validation state of filters
