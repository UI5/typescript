aggregatable?

optional aggregatable?: boolean

Defines whether the property is aggregatable. A property can only be declared aggregatable if there is a CustomAggregate whose Qualifier is equal to the property key.

extension?

optional extension?: object

Contains model-specific information.

extension.technicallyAggregatable?

optional technicallyAggregatable?: boolean

If aggregatable is set to false to exclude it from aggregate personalization on the UI, the UI still needs to know that this property is aggregatable for data requests. If this attribute is not set, the default value is the same as the value of aggregatable.

extension.technicallyGroupable?

optional technicallyGroupable?: boolean

If groupable is set to false to exclude it from group personalization on the UI, the UI still needs to know that this property is groupable for data requests. If this attribute is not set, the default value is the same as the value of groupable.

isKey?

optional isKey?: boolean

Defines whether a property is a key or part of a key in the data. A key property must be technically groupable.
