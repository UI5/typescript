Interface: TypeMap

import TypeMap from "sap/ui/mdc/util/TypeMap";

Configuration class for type handling in delegates. Allows mapping of model types to sap.ui.mdc.enums.BaseType and enables model-specific type configuration.

getBaseType()

getBaseType(sType, oFormatOptions, oConstraints): BaseType

To determine which internal controls to render, either the sap.ui.mdc.Field Field, the sap.ui.mdc.MultiValueField MultiValueField, or the sap.ui.mdc.FilterField FilterField control needs information about whether the type represents a date, a number, or another sap.ui.mdc.enums.BaseType BaseType.

As default, string is returned.
