Class: DynamicDateRangeConditionsType

import DynamicDateRangeConditionsType from "sap/ui/mdc/field/DynamicDateRangeConditionsType";

This class represents a type to map an array of conditions used in a sap.ui.mdc.FilterField FilterField control to a value of a sap.m.DynamicDateRange DynamicDateRange control.
