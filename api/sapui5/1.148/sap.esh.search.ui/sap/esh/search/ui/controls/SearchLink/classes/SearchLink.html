Class: SearchLink

import SearchLink from "sap/esh/search/ui/controls/SearchLink";

This is the SAPUI5 search link control to display attributes of search results. For attribute without navigation use control sap.esh.search.ui.controls.resultview.SearchText. Use in combination with control SearchCompositeControl by the Enterprise Search Team.
