Interface: $AxisSettings

import { $AxisSettings } from "sap/makit/Axis";

Describes the settings that can be provided to the Axis constructor.

Deprecated

As of version 1.38. MAKIT charts have been replaced with sap.viz and vizFrame in 1.38. This control will not be supported anymore from 1.38.
