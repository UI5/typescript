Class: AddPicture

import AddPicture from "sap/ca/ui/AddPicture";

Enables users to add pictures into a form. Contains PictureItem controls that describe the media. It is designed to be used simultaneously with the PictureViewer control

Deprecated

As of version 1.26. As per central UX requirements, this control is replaced by sap.m.UploadCollection. Please use the new control if you start developing an application instead of using this AddPicture control.
