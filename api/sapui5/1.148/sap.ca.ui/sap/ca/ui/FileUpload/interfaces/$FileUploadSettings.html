Interface: $FileUploadSettings

import { $FileUploadSettings } from "sap/ca/ui/FileUpload";

Describes the settings that can be provided to the FileUpload constructor.

Deprecated

As of version 1.26. This control is available in sap.m in 1.26, as sap.m.UploadCollection. Please use UploadCollection, as sap.ca.ui.FileUpload will not be supported anymore from 1.26.
