Class: DateFormat

import DateFormat from "sap/ca/ui/model/format/DateFormat";

The DateFormat is a static class for formatting and parsing date and time values according to a set of format options.

It uses sap.ui.core.format.DateFormat to format and parse dates, and adds a new style daysAgo for Date instances. With this style: - For today: "Today" will be displayed (localized) - For yesterday: "1 day ago" will be displayed (localized) - Between 2 days and 6 days in the past: "x days ago" will be displayed (localized) - In the future or more than 6 days in the past: the date will be formatted with a medium style The daysAgo style can be formatted in UTC.

Supported format options are pattern based on Unicode LDML Date Format notation. If no pattern is specified a default pattern according to the locale settings is used.

Deprecated

As of version 1.28. This control has been made available in sap.ui.core. Please use sap.ui.core.format.DateFormat instead! This control will not be supported anymore.
