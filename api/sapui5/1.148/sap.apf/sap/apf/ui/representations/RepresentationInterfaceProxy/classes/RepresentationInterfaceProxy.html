Class: RepresentationInterfaceProxy

import RepresentationInterfaceProxy from "sap/apf/ui/representations/RepresentationInterfaceProxy";

Experimental

The interface proxy passed to a representation which provides access to required APF methods. This constructor is used by apf.api. It can be also used to build unit tests that need an interface proxy between APF and representations.

Deprecated

As of version 1.136. because it is part of the deprecated package sap.apf The complete interface is subject to ongoing work and not yet stable (as of Version 1.24.0).
