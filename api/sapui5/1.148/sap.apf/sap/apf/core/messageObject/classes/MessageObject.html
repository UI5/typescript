Class: MessageObject

import MessageObject from "sap/apf/core/messageObject";

The message object represents the APF specific message object for detailed evaluation. The message object shall be created by method sap.apf.Api#createMessageObject.

Deprecated

As of version 1.136. this library is deprecated and will not be available in future major releases
