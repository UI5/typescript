Interface: MatrixUtilities

import MatrixUtilities from "sap/ui/vtm/MatrixUtilities";

Experimental

A set of utility functions for working with transformation matrices in a ISO 10303-42 format (in the form of a 1 dimensional array of 13 numbers)

Deprecated

As of version 1.96.10. because it is part of the deprecated package sap.ui.vtm As of version 1.50.0. This class is experimental and might be modified or removed in future versions.
