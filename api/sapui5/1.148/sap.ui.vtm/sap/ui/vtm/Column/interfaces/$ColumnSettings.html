Interface: $ColumnSettings

import { $ColumnSettings } from "sap/ui/vtm/Column";

Experimental

Describes the settings that can be provided to the Column constructor.

Deprecated

As of version 1.96.10. because it is part of the deprecated package sap.ui.vtm As of version 1.50.0. This class is experimental and might be modified or removed in future versions.

Properties

descriptor?

optional descriptor?: string | PropertyBindingInfo

Experimental

The descriptor is a JSON string identifying the column.

When the type property has a value of sap.ui.vtm.ColumnType.Metadata the descriptor property has the following form: '{"category":"SAP","field":"MATERIAL"}' Such descriptors can be constructed using sap.ui.vtm.DescriptorUtilities.createMetadataDescriptor.

When the type property has a value of sap.ui.vtm.ColumnType.Identifier the descriptor property has the following form: '{"source":"SAP","type":"VE_COMPONENT"}' Such descriptors can be constructed using sap.ui.vtm.DescriptorUtilities.createIdentifierDescriptor.

When the type property has a value of sap.ui.vtm.ColumnType.AppData the descriptor property has the following form: 'bomId'

If defined, overrides the cell template for the column. If this is defined, the valueFormatter and tooltipFormatter properties are ignored.

tooltip?

optional tooltip?: string | PropertyBindingInfo

Experimental

A localized string to show in the column header tooltip. If unspecified, the label value will be used as the column header tooltip.

$ElementSettings.tooltip

tooltipFormatter?

optional tooltipFormatter?: any

Experimental

If defined, this is a function that specifies the formatting of cell content tooltips for this column (overriding the default behaviour). Not used if a custom template is specified. The function must return a string containing the text to display in the tooltip (or null) for a given tree item. The first parameter to the function (which may not always be defined) is the tree item for the tree table row.

valueFormatter?

Experimental

If defined, this is a function that specifies the formatting of cell content text for this column. The function must return a string containing the text to display in the cell (or null) for a given tree item. The first parameter to the function (which may not always be defined) is the tree item for the tree table row.
