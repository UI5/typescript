Class: PresentationVariant

import PresentationVariant from "sap/fe/navigation/PresentationVariant";

This is the successor of sap.ui.generic.app.navigation.service.PresentationVariant. Creates a new instance of a PresentationVariant class. If no parameter is passed, an new empty instance is created whose ID has been set to "". Passing a JSON-serialized string complying to the Selection Variant Specification will parse it, and the newly created instance will contain the same information.
