Class: Field

import Field from "sap/ui/comp/smartmultiedit/Field";

The SmartMultiEdit.Field control enables you to edit multiple homogeneous objects simultaneously. It allows you to select a predefined item from a combo box and apply your selection to all objects being edited. In addition, SmartMultiEdit.Field can handle metadata for a specific OData property when you need to enable mass editing for multiple contexts. The contexts are handled by the sap.ui.comp.smartmultiedit.Container control.
