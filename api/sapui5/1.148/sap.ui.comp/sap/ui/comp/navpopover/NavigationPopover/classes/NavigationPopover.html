Class: NavigationPopover

import NavigationPopover from "sap/ui/comp/navpopover/NavigationPopover";

The NavigationPopover control is used to present information in a specific format. Note: This control is used by the sap.ui.comp.navpopover.NavigationPopoverHandler NavigationPopoverHandler and must not be used manually.

Deprecated

As of version 1.121. SmartLink no longer opens a NavigationPopover, it got replaced by the sap.ui.mdc.link.Panel in a sap.m.ResponsivePopover
