Class: LinkData

import LinkData from "sap/ui/comp/navpopover/LinkData";

Stores display text together with a navigation target hyperlink. The LinkData class is used by sap.ui.comp.navpopover.SmartLink SmartLink and sap.ui.comp.navpopover.SemanticObjectController SemanticObjectController to define the visible links on sap.ui.comp.navpopover.NavigationPopover NavigationPopover.
