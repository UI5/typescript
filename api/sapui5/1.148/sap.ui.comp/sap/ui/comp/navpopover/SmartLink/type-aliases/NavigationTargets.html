Type Alias: NavigationTargets

import { NavigationTargets } from "sap/ui/comp/navpopover/SmartLink";

NavigationTargets = object

Object holding the information regarding the obtained navigation targets and extra content. This is used as parameter and return value of the Promise in the navigationTargetsObtainedCallback.

Properties

actions

actions: LinkData[]

Array of available navigation target objects

extraContent

extraContent: Control | null | undefined

The control that is displayed in the extra content section on the popover. If set to null, the extra content is removed. If set to undefined, a sap.m.VBox containing the popoverForms as items is used as extra content. The popoverForms can be empty.

mainNavigation

mainNavigation: LinkData

The main navigation object

mainNavigationId

mainNavigationId: string

The text of the main link / text that is displayed in the header of the popover.

originalId

originalId: String

The ID of the SmartLink or other parent control

ownNavigation

ownNavigation: LinkData

The navigation object for the own application. This navigation option is not visible on the popover by default.

popoverForms

popoverForms: SimpleForm[]

Array containing contact data. Manipulating this property won't have an effect, it's only relevant to be streamlined with the old API. The extraContent property is used to return the intended content.

semanticAttributes

semanticAttributes: object

Map containing the semantic attributes

semanticObject

semanticObject: String

The semantic object for which the navigation targets have been retrieved
