Interface: $NavigationPopoverSettings

import { $NavigationPopoverSettings } from "sap/ui/comp/navpopover/NavigationPopover";

Describes the settings that can be provided to the NavigationPopover constructor.

Deprecated

As of version 1.121. SmartLink no longer opens a NavigationPopover, it got replaced by the sap.ui.mdc.link.Panel in a sap.m.ResponsivePopover
