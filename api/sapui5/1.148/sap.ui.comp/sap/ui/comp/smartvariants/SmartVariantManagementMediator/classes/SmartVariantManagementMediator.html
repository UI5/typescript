Class: SmartVariantManagementMediator

import SmartVariantManagementMediator from "sap/ui/comp/smartvariants/SmartVariantManagementMediator";

Can be used to manage variants. You can use this control in most controls that are enabled for key user adaptation. **Note: **On the user interface, variants are generally referred to as "views".
