Class: P13nGroupPanel

import P13nGroupPanel from "sap/m/P13nGroupPanel";

The P13nGroupPanel control is used to define group-specific settings for table personalization.

Since

1.26.0

Deprecated

As of version 1.98. Use the sap.m.p13n.GroupPanel instead.
