Class: MessageItem

import MessageItem from "sap/m/MessageItem";

A wrapper control used to hold different types of system messages. Structure: The message item holds the basic set of properties for a system message: - Type, title, subtitle and description - If the description contains markup, the markupDescription needs to be set to true, to ensure it is interpreted correctly. - If the long text description can be specified by a URL by setting, the longtextUrl property.

 -  The message item can have a single sap.m.Link after the description. It is stored in the
`link` aggregation.  Usage: **Note:** The MessageItem control replaces sap.m.MessagePopoverItem
as a more generic wrapper for messages.
