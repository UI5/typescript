Properties

mode

mode: string

The file name validation mode. The allowed values are 'include', 'exclude', or 'override'.

If the mode is 'include', the specified characters are added to the default restricted character set.

If the mode is 'exclude', the specified characters are excluded from the default resrtricted character set. If the mode is 'override', the specified characters replace the entire default restricted character set. If the mode is not set, the default restricted file name character set is used.
