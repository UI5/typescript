iGoToSection()

iGoToSection(vSectionIdentifier): object

Navigates to or focuses on the defined section.

Parameters

vSectionIdentifier

string | SectionIdentifier

The identifier of a section, or its label if passed as an object, the following pattern will be considered (please use to open sub-sections via drop-down):


{
    section: ,
    subSection:
}

to open the editable header section use pattern:


{
    section: "EditableHeaderSection"
}
