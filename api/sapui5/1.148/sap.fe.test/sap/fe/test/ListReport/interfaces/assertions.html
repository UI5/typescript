iCheckView()

iCheckView(vViewIdentifier, mState): object

Checks the view of a Multiple View List Report table.

Parameters

vViewIdentifier

string | ViewIdentifier

The identifier of a view as defined in the manifest file, or its label passed as a string if passed as an object, the following pattern will be considered:


{
    key: ,
}

Depending on property 'keepPreviousPersonalization' in the manifest, the key could be set differently within the id of the table. If necessary please check the UI control tree within the debugger.

mState

object

An object containing properties of the view to be checked Example:


{
    count: ,
}

Returns

object

The result of the sap.ui.test.Opa5#waitFor function, to be used for chained statements
