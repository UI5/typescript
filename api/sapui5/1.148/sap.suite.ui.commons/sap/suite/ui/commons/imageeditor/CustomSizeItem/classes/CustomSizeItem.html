Class: CustomSizeItem

import CustomSizeItem from "sap/suite/ui/commons/imageeditor/CustomSizeItem";

A CustomSizeItem can be used in the sap.suite.ui.commons.imageeditor.ImageEditorContainer aggregations to define custom items on the Resize, Crop Rectangle, and Crop Ellipse panels.

getRelative()

getRelative(): boolean

Gets current value of property #getRelative relative.

Specifies whether the width and height properties use relative values (true) or absolute values (false). When used in the customResizeItems aggregation of an sap.suite.ui.commons.imageeditor.ImageEditorContainer, width and height are multiplied by the width and height properties of the CustomSizeItem. When used in the customRectangleCropItems or customEllipseCropItems aggregations of an sap.suite.ui.commons.imageeditor.ImageEditorContainer, aspect ratio is set to the width and height properties of the CustomSizeItem.

Default value is false.
