Class: Shape

import Shape from "sap/suite/ui/commons/statusindicator/Shape";

Abstract shape that displays the value of the status indicator. The shape reflects the status indicator's percentage value by filling one or more of its parts (SVG shapes) with the specified color.

getFillingAngle()

getFillingAngle(): number

Gets current value of property #getFillingAngle fillingAngle.

Defines the angle at which the shape is filled. This property overrides the fillingDirection property. Accepted values include 0 through 360 degrees. For example, if you set the filling angle to 45, the shape will be filled diagonally from the lower right part of the shape to its upper left part. This property can be used only when sap.suite.ui.commons.statusindicator.FillingType is set to Linear.

Default value is undefined.

getFullAnimationDuration()

getFullAnimationDuration(): number

Gets current value of property #getFullAnimationDuration fullAnimationDuration.

Specifies the duration, in milliseconds, of the animation that would fill an empty shape to the full. The actual time it takes to change the shape's filling is proportional to the difference between the initial and the target status indicator's value. For example, a change from 20 percent to 70 percent takes only half of the time specified in the fullAnimationDuration property. If this property is set to 0, changes are applied instantly without any animation.

Default value is 0.

Returns

number

Value of property fullAnimationDuration

Deprecated

As of version 1.54.1. All animations are now limited to 250 ms.
