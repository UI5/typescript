Class: CalculationBuilder

import CalculationBuilder from "sap/suite/ui/commons/CalculationBuilder";

Calculation Builder allows you to perform arithmetic calculations on literals and variables using standard arithmetic operators as well as most common logical operators and functions. You can customize the sets of variables and functions that are visible in the calculation builder and introduce your own custom functions, as needed. Arithmetic expressions can be entered using a touch-friendly visual editor or a textual editor that provides autocomplete suggestions for variables and checks the expression syntax as you type.
