Class: ForceDirectedLayout

import ForceDirectedLayout from "sap/suite/ui/commons/networkgraph/layout/ForceDirectedLayout";

This algorithm uses the deterministic variant of the force-directed layout algorithm sap.suite.ui.commons.networkgraph.layout.ForceBasedLayout to arrange the nodes included in the network graph. It can be useful for complex graphs, where sap.suite.ui.commons.networkgraph.layout.LayeredLayout is not sufficient.
