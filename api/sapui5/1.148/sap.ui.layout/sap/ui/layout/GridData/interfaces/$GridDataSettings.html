Interface: $GridDataSettings

import { $GridDataSettings } from "sap/ui/layout/GridData";

Describes the settings that can be provided to the GridData constructor.

indent?

optional indent?: string | PropertyBindingInfo

A string type that represents the indent values of the Grid for large, medium and small screens.

Allowed values are separated by space with case insensitive Letters XL, L, M or S followed by number of columns from 1 to 11 that the container has to take, for example, L2 M4 S6, M11, s10 or l4 m4.

Note: The parameters must be provided in the order .

span?

optional span?: string | PropertyBindingInfo
