adjustLabelSpan?

optional adjustLabelSpan?: boolean | PropertyBindingInfo | `{${string}}`

If set, the usage of labelSpanL and labelSpanM are dependent on the number of sap.ui.layout.form.FormContainer FormContainers in one row. If only one sap.ui.layout.form.FormContainer FormContainer is displayed in one row, labelSpanM is used to define the size of the label. This is the same for medium and large Forms. This is done to align the labels on forms where full-size sap.ui.layout.form.FormContainer FormContainers and multiple-column rows are used in the same sap.ui.layout.form.Form Form (because every sap.ui.layout.form.FormContainer FormContainer has its own sap.ui.layout.Grid Grid inside).

If not set, the usage of labelSpanL and labelSpanM are dependent on the sap.ui.layout.form.Form Form size. The number of sap.ui.layout.form.FormContainer FormContainers doesn't matter in this case.

singleContainerFullSize?

optional singleContainerFullSize?: boolean | PropertyBindingInfo | `{${string}}`

If the sap.ui.layout.form.Form Form contains only one single sap.ui.layout.form.FormContainer FormContainer and this property is set, the sap.ui.layout.form.FormContainer FormContainer is displayed using the full size of the sap.ui.layout.form.Form Form. In this case the properties columnsXL, columnsL and columnsM are ignored.

In all other cases the sap.ui.layout.form.FormContainer FormContainer is displayed in the size of one column.
