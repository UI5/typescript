Class: Chart

import Chart from "sap/fe/macros/Chart";

Building block used to create a chart based on the metadata provided by OData V4. demo:sap/fe/core/fpmExplorer/index.html#/buildingBlocks/chart/chartDefault Overview of Building Blocks

Usually, a contextPath and metaPath is expected.

Usage example:


<macros:Chart id="MyChart" contextPath="/RootEntity" metaPath="@com.sap.vocabularies.UI.v1.Chart" />

setPresentationVariant()

setPresentationVariant(presentationVariant): Promise<void>

Set the presentation variant for the mdc chart. The json format retrieved by using the get PresentationVariant button in the linked FPM sample should be followed while trying to set the PresentationVariant as needed. The values dimensions, measures and other properties should also be given in the valid format and null or empty values should be avoided. One dimension attribute should have only one role associated with it on a given chart.
