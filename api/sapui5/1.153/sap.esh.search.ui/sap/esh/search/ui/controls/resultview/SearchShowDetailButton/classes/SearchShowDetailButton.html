Class: SearchShowDetailButton

import SearchShowDetailButton from "sap/esh/search/ui/controls/resultview/SearchShowDetailButton";

This is the SAPUI5 search show detail button control to navigate to the detail of a result item. Use in combination with sap.esh.search.ui.controls.SearchCompositeControl by the Enterprise Search Team. The master detail mode of the result view must be activated (see config property 'resultviewMasterDetailMode'). Place this button on custom result grid view tiles (see config property 'customGridView'). The press event of this button will fire the event 'showResultDetail' (see sap.esh.search.ui.controls.SearchCompositeControl).
