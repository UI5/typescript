Class: SearchText

import SearchText from "sap/esh/search/ui/controls/resultview/SearchText";

This is the SAPUI5 search text control to display attributes of search results. For attribute with navigation use control sap.esh.search.ui.controls.SearchLink. Use in combination with control SearchCompositeControl by the Enterprise Search Team.

Constructs a new SearchText to display an attribute (text only, no navigation) on custom grid control tiles.
