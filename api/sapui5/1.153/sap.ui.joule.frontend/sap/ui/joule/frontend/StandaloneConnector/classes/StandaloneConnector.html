Class: StandaloneConnector

import StandaloneConnector from "sap/ui/joule/frontend/StandaloneConnector";

Experimental

Connector for standalone (non-FLP) Joule integration.

This class handles direct communication with the Joule webclient API when running outside of SAP Fiori Launchpad. It supports both immediate registration (when Joule is already loaded) and pre-registration (when Joule loads later).

For a unified API that works in both FLP and standalone environments, use sap.ui.joule.frontend.JouleConnector instead.

As of version 1.151.

Registers callbacks with the Joule webclient.
