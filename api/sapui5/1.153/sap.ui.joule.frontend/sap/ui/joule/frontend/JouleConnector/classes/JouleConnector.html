Class: JouleConnector

import JouleConnector from "sap/ui/joule/frontend/JouleConnector";

Experimental

Unified connector for SAP Joule frontend action integration.

This is the main entry point for integrating frontend actions with SAP Joule. It automatically detects the runtime environment (FLP or standalone) and uses the appropriate communication mechanism.

As of version 1.151.

registerActions()

registerActions(fnGetActions?): JouleConnector

Experimental

Registers app-specific frontend actions with Joule.

Generic UI actions (describeUI, describeUIElement, setFields, executeAction) are automatically registered at library load time under a separate client ID. This method registers app-specific actions independently under the app's own client ID.

Parameters

fnGetActions?

Function

A function that returns an array of app-specific frontend action definitions. This function is called by Joule for each user prompt to get the available actions.

registerCallback()

registerCallback(sName, fnHandler): JouleConnector

Experimental

Registers an additional callback with Joule beyond frontend actions.

Use this method to register callbacks for lifecycle events, context changes, chat events, or other Joule webclient interactions that are not frontend actions.

Can be called before or after #registerActions. If called after, the callback is added to the already-connected bridge immediately.

Parameters

sName

string

The callback name (e.g., "onContextChange", "onChatEvent"). Must not be "getFrontendActions" — use registerActions() for that.

fnHandler

Function
