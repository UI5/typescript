Class: SessionHandler

import SessionHandler from "sap/ushell/services/SessionHandler";

The Unified Shell's session handler service. Manages the timeout of an FLP session: - Announces user activity to the platform (via the UShell container service). - Maintains user activity data in local storage to support multi-browser-tab use cases. - Notifies the user once the session is about to end, offering the option to extend the session.

Note: To retrieve a valid instance of this service, it is necessary to call sap.ushell.Container#getServiceAsync.


  sap.ui.require(["sap/ushell/Container"], async function (Container) {
    const SessionHandler = await Container.getServiceAsync("SessionHandler");
    // do something with the SessionHandler service
  });

This service should be available in any FLP context (native, iframe, ...).

Methods

notifyUserActivity()

notifyUserActivity(): void

Notifies the FLP that the user is currently active, so the FLP treats the session as active and defers idle warnings / automatic sign-out.

Intended for apps whose user activity the FLP cannot observe directly (e.g. content embedded in an iframe). The app decides when the user is active and calls this to signal it.
