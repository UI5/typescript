hasNativeLogoutCapability()

hasNativeLogoutCapability(): boolean

Detects whether NWBC can logout natively.

NWBC exposes a feature bit vector via the "getNwbcFeatureBits" method of the private "epcm" object. This is expected to be a string in hex format representing 4 bits, where the second least significant bit represents native logout capability.

For example: "B" = 1011, second last bit is 1, therefore native logout capability is enabled.

Returns

boolean

Whether the browser can logout natively.
