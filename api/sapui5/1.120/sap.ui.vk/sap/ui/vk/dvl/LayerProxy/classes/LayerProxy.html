Class: LayerProxy

import LayerProxy from "sap/ui/vk/dvl/LayerProxy";

Provides a proxy object to the layer in the node hierarchy.

Layer is a list of nodes. One node hierarchy can have multiple layers. One node can be included in multiple layers.

Objects of this type should only be created with the sap.ui.vk.NodeHierarchy#createLayerProxy sap.ui.vk.NodeHierarchy.createLayerProxy method and destroyed with the sap.ui.vk.NodeHierarchy#destroyLayerProxy sap.ui.vk.NodeHierarchy.destroyLayerProxy method.
