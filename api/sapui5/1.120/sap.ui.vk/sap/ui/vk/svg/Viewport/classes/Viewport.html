getViewInfo()

getViewInfo(query?): object

Retrieves information about the current camera view in the scene, and saves the information in a JSON-like object. The information can then be used at a later time to restore the scene to the same camera view using the sap.ui.vk.Viewport#setViewInfo setViewInfo method.

Parameters

query?

Query object which indicates what information to be retrieved.

selection?

boolean | object

Indicator to retrieve selection information.

visibility?

boolean | { mode?: VisibilityMode; }

Indicator to retrieve visibility information.

Returns

object

JSON-like object which holds the current view information. See sap.ui.vk.Viewport#setViewInfo setViewInfo. In addition to properties defined in sap.ui.vk.Viewport#setViewInfo setViewInfo the output from sap.ui.vk.Viewport#getViewInfo getViewInfo contains camera view and projection matrices

setViewInfo()

setViewInfo(viewInfo, flyToDuration?): this

Sets the current scene to use the camera view information acquired from the sap.ui.vk.Viewport#getViewInfo getViewInfo method. Internally, the setViewInfo method activates certain steps at certain animation times, and then changes the camera position, rotation and field of view (FOV) / zoom factor.

Parameters

viewInfo

A JSON-like object containing view information acquired using the sap.ui.vk.Viewport#getViewInfo getViewInfo method.

camera?

object

A JSON-like object containing the camera information.

selection?

{ outlined: string[]; selected: string[]; }

A JSON-like object containing the selection information.

selection.outlined

string[]

List of Ids of outlined nodes.

selection.selected

string[]

List of Ids of selected nodes.

visibility?

{ changes: string[]; hidden: string[]; mode: VisibilityMode; visible: string[]; }

A JSON-like object containing the visibility information.

visibility.changes

string[]

List of Ids of nodes with inverted visibility.

visibility.hidden

string[]

List of Ids of hidden nodes.

visibility.mode

VisibilityMode

If the mode equals to sap.ui.vk.VisibilityMode.Complete complete then the visible and hidden fields are defined. If the mode equals sap.ui.vk.VisibilityMode.Differences differences then the changes field is defined.

visibility.visible

string[]

List of Ids of visible nodes.
