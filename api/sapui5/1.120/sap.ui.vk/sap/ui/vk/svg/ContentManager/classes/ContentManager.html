Class: ContentManager

import ContentManager from "sap/ui/vk/svg/ContentManager";

Provides a content manager object that uses to load 2D content.

When registering a content manager resolver with sap.ui.vk.ContentConnector.addContentManagerResolver sap.ui.vk.ContentConnector.addContentManagerResolver you can pass a function that will load a model and merge it into the three.js scene.
