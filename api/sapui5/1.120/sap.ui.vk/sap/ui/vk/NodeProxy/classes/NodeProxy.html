Class: NodeProxy

import NodeProxy from "sap/ui/vk/NodeProxy";

Provides a proxy object to the node in the node hierarchy.

Objects of this type should only be created with the sap.ui.vk.NodeHierarchy#createNodeProxy sap.ui.vk.NodeHierarchy.createNodeProxy method. and destroyed with the sap.ui.vk.NodeHierarchy#destroyNodeProxy sap.ui.vk.NodeHierarchy.destroyNodeProxy method.
