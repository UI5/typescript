Properties

alphaExponent?

optional alphaExponent?: string | PropertyBindingInfo

Exponent for the alphaChannel aE = 1 : alpha Channel remains linear 0 < aE < 1 : (e.g. aE=0.5 "square root") sub linear alpha channeling (lower value colors remain longer visible; range appears wider) aE > 1 (e.g. aE=2: "squared") above linear alpha channeling ( lower value colors remain shortly visible; range appears chopped)

behavior?

optional behavior?: string | PropertyBindingInfo

Behavior of the HeatPoint, 0 Density Map, 2: Heat Map, 1: Intermediate.

colorExponent?

optional colorExponent?: string | PropertyBindingInfo

Exponent for the color aE = 1 : Linear Gradient 0 < aE < 1 : Sublinear Gradient; i.E. with cE=0.5 point values are square rooted before usage [share of lower value cols will decrease] aE > 1 : Higher Level Gradient; i.E. with cE=2 point values are squared before usage [share of lower value cols will increase]

gradient?

optional gradient?: any[] | PropertyBindingInfo | `{${string}}`

Gradient Definition. Can be either provided as Ressource - then it is type string. Or as Array [n0,c0,n1,c1,...,nk,ck] (ni > ni-1; ci respective colors) with an arbitrary number of color stops as in the following Example: [0,'rgba(0,255,0,1)',220,'rgba(255,255,0,1)',255,'rgba(255,0,0,1)']
