Class: Container

import Container from "sap/ui/vbm/Container";

Specific Visual Object element acting as a container for other controls. A Container is positioned at the given position on the map. It can aggregate other controls, which will then move with the map. Since a Container is not a real visual object most features borrowed from VoBase will not work. There is no label, no edit mode, and no drop support. Events like click will only be fired if the aggregated control is not handling them.
