Class: FileUpload

import FileUpload from "sap/ca/ui/FileUpload";

Allows you to display a list of uploaded files. You can also upload a new one, rename or delete them

Deprecated

(since 1.26) - This control is available in sap.m in 1.26, as sap.m.UploadCollection. Please use UploadCollection, as sap.ca.ui.FileUpload will not be supported anymore from 1.26.
