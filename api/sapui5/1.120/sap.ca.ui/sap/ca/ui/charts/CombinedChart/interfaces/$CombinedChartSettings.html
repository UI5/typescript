Interface: $CombinedChartSettings

import { $CombinedChartSettings } from "sap/ca/ui/charts/CombinedChart";

Describes the settings that can be provided to the CombinedChart constructor.

Deprecated

(since 1.24) - Sap.ca charts have been replaced with sap.viz and vizFrame in 1.24. The UI5 control "sap.viz.ui5.controls.VizFrame" serves as a single point of entry for all the new charts. Now that 1.24 is available you are asked to use sap.viz charts and the VizFrame instead! This control will not be supported anymore from 1.24.
