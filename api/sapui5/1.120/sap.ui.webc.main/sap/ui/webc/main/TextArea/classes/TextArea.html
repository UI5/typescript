Class: TextArea

import TextArea from "sap/ui/webc/main/TextArea";

Experimental

Overview:

The sap.ui.webc.main.TextArea component is used to enter multiple lines of text.

When empty, it can hold a placeholder similar to a sap.ui.webc.main.Input. You can define the rows of the sap.ui.webc.main.TextArea and also determine specific behavior when handling long texts.

CSS Shadow Parts:

CSS Shadow Parts allow developers to style elements inside the Shadow DOM. The sap.ui.webc.main.TextArea exposes the following CSS Shadow Parts: - textarea - Used to style the native textarea

getShowExceededText()

getShowExceededText(): boolean

Experimental

Gets current value of property #getShowExceededText showExceededText.

Determines whether the characters exceeding the maximum allowed character count are visible in the component.

If set to false, the user is not allowed to enter more characters than what is set in the maxlength property. If set to true the characters exceeding the maxlength value are selected on paste and the counter below the component displays their number.

Default value is false.
