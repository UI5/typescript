Interface: $TreeSettings

import { $TreeSettings } from "sap/ui/webc/main/Tree";

Experimental

Describes the settings that can be provided to the Tree constructor.

Deprecated

(since 1.120) - this Web Components consumption model has been discarded. Until an alternative Web Components consumption model is available in the future, use sap.m and sap.f controls with similar functionality. (since 1.92.0) - This control is experimental and its API might change significantly.

Experimental

Fired when a tree item is expanded or collapsed. Note: You can call preventDefault() on the event object to suppress the event, if needed. This may be handy for example if you want to dynamically load tree items upon the user expanding a node.
