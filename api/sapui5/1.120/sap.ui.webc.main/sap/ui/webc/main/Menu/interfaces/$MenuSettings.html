Interface: $MenuSettings

import { $MenuSettings } from "sap/ui/webc/main/Menu";

Experimental

Describes the settings that can be provided to the Menu constructor.

Deprecated

(since 1.120) - this Web Components consumption model has been discarded. Until an alternative Web Components consumption model is available in the future, use sap.m and sap.f controls with similar functionality. (since 1.102.0) - This control is experimental and its API might change significantly.
