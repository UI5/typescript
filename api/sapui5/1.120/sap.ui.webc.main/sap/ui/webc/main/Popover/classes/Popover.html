Class: Popover

import Popover from "sap/ui/webc/main/Popover";

Experimental

Overview:

The sap.ui.webc.main.Popover component displays additional information for an object in a compact way and without leaving the page. The Popover can contain various UI elements, such as fields, tables, images, and charts. It can also include actions in the footer.

Structure:

The popover has three main areas: - Header (optional) - Content - Footer (optional)

Note: The sap.ui.webc.main.Popover is closed when the user clicks or taps outside the popover or selects an action within the popover. You can prevent this with the modal property.

CSS Shadow Parts:

CSS Shadow Parts allow developers to style elements inside the Shadow DOM. The sap.ui.webc.main.Popover exposes the following CSS Shadow Parts: - header - Used to style the header of the component - content - Used to style the content of the component - footer - Used to style the footer of the component
