Function: includeScript()

includeScript(vUrl, vId?, fnLoadCallback?, fnErrorCallback?): void | Promise<Event>

Includes the script (via -tag) into the head for the specified sUrl and optional sId.

Parameters

vUrl

string | { attributes?: object; id?: string; url: string; }

the URL of the script to load or a configuration object

string

Type Literal

{ attributes?: object; id?: string; url: string; }

the URL of the script to load or a configuration object

attributes?

object

map of attributes that should be used for the script tag

id?

string

id that should be used for the script tag

url

string

the URL of the script to load

vId?

string | object

id that should be used for the script tag or map of attributes

fnLoadCallback?

(p1) => void

callback function to get notified once the script has been loaded

fnErrorCallback?

(p1) => void

callback function to get notified once the script loading failed

Returns

void | Promise<Event>

When using the configuration object a Promise will be returned. The documentation for the fnLoadCallback applies to the resolve handler of the Promise and the one for the fnErrorCallback applies to the reject handler of the Promise.
