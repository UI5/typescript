Class: UI5Date

import UI5Date from "sap/ui/core/date/UI5Date";

A date implementation considering the configured time zone

A subclass of JavaScript Date that considers the configured time zone, see sap.ui.core.Configuration#getTimezone. All JavaScript Date functions that use the local browser time zone, like getDate, setDate, and toString, are overwritten and use the configured time zone to compute the values.

Use module:sap/ui/core/date/UI5Date.getInstance to create new date instances.

Note: Adjusting the time zone in a running application can lead to unexpected data inconsistencies. For more information, see sap.ui.core.Configuration#setTimezone.

getInstance()

static getInstance(vYearOrValue?, vMonthIndex?, vDay?, vHours?, vMinutes?, vSeconds?, vMilliseconds?): Date | UI5Date

Creates a date instance (either JavaScript Date or UI5Date) which considers the configured time zone wherever JavaScript Date uses the local browser time zone, for example in getDate, toString, or setHours. The supported parameters are the same as the ones supported by the JavaScript Date constructor.

Note: Adjusting the time zone in a running application can lead to unexpected data inconsistencies. For more information, see sap.ui.core.Configuration#setTimezone. See: sap.ui.core.Configuration#getTimezone
