Class: DateTimeWithTimezone

import DateTimeWithTimezone from "sap/ui/model/odata/type/DateTimeWithTimezone";

This class represents the DateTimeWithTimezone composite type which has the parts timestamp and time zone. The type formats the timestamp part using the time zone part. For this, the timestamp part has to be provided in the UTC time zone. When using this type with the sap.ui.model.odata.v2.ODataModel, you need to set the parameter useUndefinedIfUnresolved for both parts.

For more information and some examples how to use this class, see Dates, Times, Timestamps, and Time Zones.

getPartsIgnoringMessages()

getPartsIgnoringMessages(): number[]

Gets an array of indices that determine which parts of this type shall not propagate their model messages to the attached control. Prerequisite is that the corresponding binding supports this feature, see sap.ui.model.Binding#supportsIgnoreMessages. If the showTimezone format option is set to false, the time zone is not shown in the control, and the part for the time zone shall not propagate model messages to the control. Analogously, if the format option showDate and showTime are both set to false, the date and time are not shown in the control, and the parts for the date and time shall not propagate model messages to the control.
