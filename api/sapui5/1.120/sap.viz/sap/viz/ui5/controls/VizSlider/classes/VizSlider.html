Call Signature

attachRangeChanged(oData, fnFunction, oListener?): this

Attaches event handler fnFunction to the #event:rangeChanged rangeChanged event of this sap.viz.ui5.controls.VizSlider.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.viz.ui5.controls.VizSlider itself.
