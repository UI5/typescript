getFormatString()

getFormatString(): any

Gets current value of property #getFormatString formatString.

The pattern is used to format the measures/timeDimensions displayed in Tooltip. If value type of format string is String or an object with 'formatPattern' and 'dataUnit' values defined, the value will be used to format all measures(not works with TimeDimension). The value of ‘formatPattern’ here is a string to define the format pattern of numbers, and value of ‘dataUnit’ is a postfix string to indicate the unit of measure. If value type is Object whose key is measure/timeDimension name, the possible value type is string or an object with ‘formatPattern’ and ‘dataUnit’ values defined. And each string value will be used to format the specified measure or time dimension. And TimeDimension does not support 'dataUnit'.
