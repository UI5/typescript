Class: BaseDeltaRectangle

import BaseDeltaRectangle from "sap/gantt/simple/BaseDeltaRectangle";

BaseDeltaRectangle represents a basic shape that creates rectangles. It is defined by corner positions, width and height. The rectangle may have their corners rounded.

1.84
