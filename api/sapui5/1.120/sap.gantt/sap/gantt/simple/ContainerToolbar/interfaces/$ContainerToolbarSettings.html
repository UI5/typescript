alignCustomContentToRight?

optional alignCustomContentToRight?: boolean | PropertyBindingInfo | `{${string}}`

Defines how the toolbar custom content is aligned. If set to true, the custom content in the toolbar is right-aligned. If set to false, it's left-aligned. If a sap.gantt.simple.ContainerToolbarPlaceholder with a Spacer type is used in the content aggregation, the alignment of the content depends on this spacer.
