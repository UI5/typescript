Class: TextRuleConfiguration

import TextRuleConfiguration from "sap/rules/ui/TextRuleConfiguration";

Since

1.4

The sap.rules.ui.TextRuleConfiguration element provides the ability to define specific properties that will be applied when rendering the sap.rules.ui.RuleBuilder in decision table mode.
