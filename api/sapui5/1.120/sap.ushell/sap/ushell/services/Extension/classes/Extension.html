Class: Extension

import Extension from "sap/ushell/services/Extension";

Experimental

The Unified Shell's Extension service. Allows adding extensions on the user's home page.

Note: To retrieve a valid instance of this service, it is necessary to call sap.ushell.Container.getServiceAsync("Extension"). For details, see sap.ushell.services.Container#getServiceAsync.

All extension items and extension areas are instantiated as invisible. You have to call .show<...> to make them visible.

Since

1.120.0 (since 1.120.0) - Restriction: API calls might be ignored for apps running in an iframe

addUserSettingsEntry()

addUserSettingsEntry(properties): Promise<any>

Experimental

Adds an entry to the user settings dialog box including the UI control that appears when the user clicks the new entry, and handling of user settings actions such as SAVE and CANCEL. Restriction: Might be ignored for apps running in an iframe

Parameters

properties

The data of the new added user settings entry.

content

Function

A function that resolves the content which has to be a sap.ui.core.Control. A SAPUI5 view instance can also be returned. The result will be displayed in the settings as content for this entry.

entryHelpID?

string

The ID of the object.

onCancel

Function

A callback which is called when the user closes the user settings dialog without saving any changes.

onSave

Function

A callback which is called when the user clicks "save" in the user settings dialog. The function has to return a native promise. If an error occurs, pass the error message via rejected promise. Errors are displayed in the common log.

provideEmptyWrapper?

boolean

Set this value to true if you want that your content is displayed without the standard header.

title

string

The title of the entry to be presented in the list in the user settings dialog box. We recommend using a string from the translation bundle.

value

string | Function

A string to be presented as the sub title of the entry OR a function which resolves the sub title.

Returns

Promise<any>

Resolves once the settings entry was added.
