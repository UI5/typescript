confirm()

confirm(sMessage, fnCallback, sTitle?, vActions?): void

Shows an confirmation dialog on the screen.

The callback is called with the following signature: function(Action) where Action is the action type that the user has tapped. For example, when the user has pressed the close button, a sap.m.MessageBox.Action.Close is returned.

If no actions are provided, "OK" and "Cancel" will be shown. In this case Action is set by one of the following three values: 1. sap.m.MessageBox.Action.OK: "OK" (confirmed) button is tapped. 2. sap.m.MessageBox.Action.Cancel: "Cancel" (unconfirmed) button is tapped. 3. null: Confirm dialog is closed by calling sap.m.InstanceManager.closeAllDialogs()

Parameters

sMessage

string

the localized message as plain text

fnCallback

() => string

callback function

sTitle?

string

the localized title as plain text

vActions?

string | string[] | typeof Action | (typeof Action | "ABORT" | "CANCEL" | "CLOSE" | "DELETE" | "IGNORE" | "NO" | "OK" | "RETRY" | "YES")[]

Either a single action, or an array of two actions. If no action(s) are given, the single action MessageBox.Action.OK is taken as a default for the parameter. If more than two actions are given, only the first two actions are taken. Custom action string(s) can be provided, and then the translation of custom action string(s) needs to be done by the application.

errorWithDetails()

errorWithDetails(message, detailControl?, title?, buttons?): Dialog

Shows an error message with details on the screen. If more than one control should be shown, an {sap.m.VBox } can be used. The default title is "error". If no custom buttons are given, an emphasized "close" button is shown.
