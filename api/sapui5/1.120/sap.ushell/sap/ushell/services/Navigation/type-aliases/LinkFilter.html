optional params?: object

Matches the parameters of a link. Simple format:


{
   P1: "B",
   P2: ["e", "j"]
}

Extended format:


   {
      P1: { value: "v1" },
      P2: { value: ["v2", "v3"] },
      P3: { value: "v4", required: true }
   }

required: Whether the parameter is be required (true) or not (false) in the signature of the matching target. Note that this option is only effective on platforms using the sap.ushell.services.ClientSideTargetResolution
