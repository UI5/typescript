Interface: $CarouselSettings

import { $CarouselSettings } from "sap/m/Carousel";

Describes the settings that can be provided to the Carousel constructor.

Properties

activePage?

optional activePage?: string | Control

Provides getter and setter for the currently displayed page. For the setter, argument may be the control itself, which must be member of the carousel's page list, or the control's id. The getter will return the control id

arrowsPlacement?

optional arrowsPlacement?: PropertyBindingInfo | `{${string}}` | CarouselArrowsPlacement | "Content" | "PageIndicator"

Defines where the carousel's arrows are placed. Default is sap.m.CarouselArrowsPlacement.Content used to place the arrows on the sides of the carousel. Alternatively sap.m.CarouselArrowsPlacement.PageIndicator can be used to place the arrows on the sides of the page indicator.

backgroundDesign?

optional backgroundDesign?: PropertyBindingInfo | `{${string}}` | BackgroundDesign | "Solid" | "Translucent" | "Transparent"

Defines the carousel's background design. Default is sap.m.BackgroundDesign.Translucent.

pageIndicatorPlacement?

optional pageIndicatorPlacement?: "Left" | "Right" | "Auto" | PropertyBindingInfo | `{${string}}` | "Horizontal" | "Vertical" | PlacementType | "Bottom" | "HorizontalPreferedLeft" | "HorizontalPreferedRight" | "HorizontalPreferredLeft" | "HorizontalPreferredRight" | "PreferredBottomOrFlip" | "PreferredLeftOrFlip" | "PreferredRightOrFlip" | "PreferredTopOrFlip" | "Top" | "VerticalPreferedBottom" | "VerticalPreferedTop" | "VerticalPreferredBottom" | "VerticalPreferredTop"
