labelFor?

optional labelFor?: string | Control

Association to the labelled control. By default, the label sets the for attribute to the ID of the labelled control. This can be changed by implementing the function getIdForLabel on the labelled control.

required?

optional required?: boolean | PropertyBindingInfo | `{${string}}`

Indicates that user input is required for input control labeled by the sap.m.Label. When the property is set to true and associated input field is empty an asterisk character is added to the label text.

showColon?

optional showColon?: boolean | PropertyBindingInfo | `{${string}}`

Defines whether a colon (:) character is added to the label.

Note: By default when the Label is in the sap.ui.layout.form.Form and sap.ui.layout.form.SimpleForm controls the colon (:) character is displayed automatically regardless of the value of the showColon property.

Since

1.98

optional wrapping?: boolean | PropertyBindingInfo | `{${string}}`

Determines the wrapping of the text within the Label. If set to true the Label will wrap, when set to false the Label will be truncated and replaced with ellipsis which is the default behavior.
