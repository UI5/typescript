groupName?

optional groupName?: string | PropertyBindingInfo

Name of the radio button group the current radio button belongs to. You can define a new name for the group. If no new name is specified, this radio button belongs to the sapMRbDefaultGroup per default. Default behavior of a radio button in a group is that when one of the radio buttons in a group is selected, all others are unselected.

Note To ensure screen reader support it is recommended to use the sap.m.RadioButtonGroup RadioButtonGroup wrapper instead of using the groupName property. Use this property only in cases where a wrapper control will handle the screen reader support. For example such wrappers are sap.m.List, sap.m.Table and sap.f.GridList.
