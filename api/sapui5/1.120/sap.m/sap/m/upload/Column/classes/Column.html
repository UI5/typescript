Class: Column

import Column from "sap/m/upload/Column";

Experimental

The sap.m.upload.Column allows defining personalization properties for a column. This Element is built on sap.m.Column sap.m.column. It is supposed to be used only with the columns aggregation of sap.m.upload.UploadSetwithTable UploadSetwithTable control.
