getValueHelpUITypes()

getValueHelpUITypes(oControl): DynamicDateValueHelpUIType[]

Defines the UI types of the option. They are used to create predefined UI for the DynamicDateRange's value help dialog corresponding to this option. The types are DynamicDateValueHelpUIType instances. Their possible values are "date", "datetime", "daterange", "month", "int". The created UI consists of Calendar or Input controls.
