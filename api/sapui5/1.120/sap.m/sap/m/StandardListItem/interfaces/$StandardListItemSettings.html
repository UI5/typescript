adaptTitleSize?

optional adaptTitleSize?: boolean | PropertyBindingInfo | `{${string}}`

By default, the title size adapts to the available space and gets bigger if the description is empty. If you have list items with and without descriptions, this results in titles with different sizes. In this case, it can be better to switch the size adaption off by setting this property to false.

Since

1.16.3

avatar?

optional avatar?: Avatar

A sap.m.Avatar control instance that, if set, is used instead of an icon or image.

The size of the Avatar control depends on the insetIcon property of StandardListItem. The displaySize property of the Avatar control is not supported. If the insetIcon property of StandardListItem is set to true, the size of the Avatar control is set to XS; if the insetIcon property of StandardListItem is set to false, the size of the Avatar control is set to "S".

Since

1.98

iconDensityAware?

optional iconDensityAware?: boolean | PropertyBindingInfo | `{${string}}`

By default, one or more requests are sent to get the density perfect version of the icon if the given version of the icon doesn't exist on the server. Note: If bandwidth is a key factor for the application, set this value to false.

iconInset?

optional iconInset?: boolean | PropertyBindingInfo | `{${string}}`

Defines the indentation of the icon. If set to false, the icon will not be shown as embedded. Instead it will take the full height of the list item.

info?

optional info?: string | PropertyBindingInfo

Defines an additional information text. Note: A wrapping of the information text is also supported as of version 1.95, if wrapping=true. Although long strings are supported for the information text, it is recommended to use short strings. For more details, see #getWrapping wrapping.

wrapCharLimit?

optional wrapCharLimit?: number | PropertyBindingInfo | `{${string}}`

This property can be used to change the default character limits for the wrapping behavior.

If this property is set to 0, then the default character limit used by the wrapping behavior is used. For details see #getWrapping wrapping.

Note:

0 or a positive integer must be used for this property.

Since

1.94

wrapping?

optional wrapping?: boolean | PropertyBindingInfo | `{${string}}`

Defines the wrapping behavior of title and description texts.

Note:

In the desktop mode, initial rendering of the control contains 300 characters along with a button to expand and collapse the text whereas in the phone mode, the character limit is set to 100 characters. A wrapping of the information text is supported as of 1.95. But expanding and collapsing the information text is not possible. A wrapping of the information text is disabled if infoStateInverted is set to true.

Since

1.67
