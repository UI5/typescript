initialFocus?

optional initialFocus?: PropertyBindingInfo | `{${string}}` | "List" | "SearchField" | SelectDialogInitialFocus

Specifies the control that will receive the initial focus.

Note: When the growing property is set to true, you can set the initial focus to sap.m.SelectDialogInitialFocus.SearchField. In this way the user can easily search for items that are not currently visible.
