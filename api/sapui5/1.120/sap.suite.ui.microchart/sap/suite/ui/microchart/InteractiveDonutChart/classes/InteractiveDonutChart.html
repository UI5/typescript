Class: InteractiveDonutChart

import InteractiveDonutChart from "sap/suite/ui/microchart/InteractiveDonutChart";

The InteractiveDonutChart control belongs to a chart control group in the MicroChart library with a number of interactive features. These interactive features provide more information on a chart value. For example, by selecting a segment you can get more details on the displayed value.
