Class: Component

import Component from "sap/fe/core/fpm/Component";

Experimental

Component that can be used as a wrapper component for custom pages. The component can be used in case you want to use SAP Fiori elements Building Blocks or XML template constructions. You can either extend the component and set the viewName and contextPath within your code or you can use it to wrap your custom XML view directly the manifest when you define your custom page under sapui5/routing/targets:


"myCustomPage": {
"type": "Component",
"id": "myCustomPage",
"name": "sap.fe.core.fpm",
"title": "My Custom Page",
"options": {
	"settings": {
		"viewName": "myNamespace.myView",
		"contextPath": "/MyEntitySet"
		}
	}
}
