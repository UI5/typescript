Abstract Class: ValueHelp

import ValueHelp from "sap/ui/mdc/ValueHelp";

Experimental

The ValueHelp element can be assigned to the sap.ui.mdc.Field Field, sap.ui.mdc.MultiValueField MultiValueField, and sap.ui.mdc.FilterField FilterField controls using the valueHelp association. One ValueHelp element instance can be assigned to multiple fields (like in different table rows). It should be placed in the control tree on the container holding the fields.

Since

1.95.0 (since 1.95.0)

getValidateInput()

getValidateInput(): boolean

Experimental

Gets current value of property #getValidateInput validateInput.

If this property is set, the user input of the corresponding field is validated against the value help. If no entry is found for the user input, an error is shown on the field.

If this property is not set, the user input is still checked against the value help. But if no entry is found, the user input is set to the field if the used data type allows this. (A type parsing error is shown if the user input adheres to the requirements of the used data type.)

Default value is true.

Returns

boolean

Value of property validateInput
