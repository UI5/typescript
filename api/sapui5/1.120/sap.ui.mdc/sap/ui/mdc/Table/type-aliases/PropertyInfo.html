Type Alias: PropertyInfo

import { PropertyInfo } from "sap/ui/mdc/Table";

PropertyInfo = PropertyInfo & object

An object literal describing a data property in the context of an sap.ui.mdc.Table.

When specifying the PropertyInfo objects in the sap.ui.mdc.Table#getPropertyInfo propertyInfo property, the following attributes need to be specified: - name - path - dataType - formatOptions - constraints - maxConditions - caseSensitive - visualSettings.widthCalculation - propertyInfos - groupable - key - unit - text

If the property is complex, the following attributes need to be specified: - name - visualSettings.widthCalculation - propertyInfos (all referenced properties must be specified)
