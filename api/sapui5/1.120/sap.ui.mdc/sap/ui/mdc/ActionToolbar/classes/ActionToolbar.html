Class: ActionToolbar

import ActionToolbar from "sap/ui/mdc/ActionToolbar";

The ActionToolbar control can be used in the sap.ui.mdc.Chart Chart and sap.ui.mdc.Table Table controls to display actions. The control handles key user adaptation and positioning of the actions depending on the given layout information. Note: The content aggregation of the control must not be used.
