Class: Field

import Field from "sap/ui/mdc/Field";

Experimental

The Field control is used to bind its value to data of a certain data type. Based on the data type settings, a default control is rendered by the Field as follows:

 - In display mode, usually a sap.m.Text Text control is rendered.
 - If `multipleLines` is set, an sap.m.ExpandableText ExpandableText control is rendered.
 - If `fieldInfo` is set and it is configured to be triggerable, a sap.m.Link Link control is
rendered.
 - In edit mode, usually an sap.m.Input Input control is rendered.
 - If `multipleLines` is set, a sap.m.TextArea TextArea control is rendered.
 - If a date type is used, a sap.m.DatePicker DatePicker control is rendered.
 - If a date/time type is used, a sap.m.DateTimePicker DateTimePicker control is rendered.
 - If a time type is used, a sap.m.TimePicker TimePicker control is rendered.
 - If a currency or unit type is used, two sap.m.Input Input controls are rendered, one for
number and one for unit.

attachChange()

Call Signature

attachChange(oData, fnFunction, oListener?): this

Experimental

Attaches event handler fnFunction to the #event:change change event of this sap.ui.mdc.Field.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.ui.mdc.Field itself.

This event is fired when the value property of the field is changed by user interaction.

Note This event is only triggered if the used content control has a change event.
