Class: Chart

import Chart from "sap/ui/mdc/Chart";

Experimental

The Chart control creates a chart based on metadata and the configuration specified. Note: The inner chart needs to be assigned ChartDelegate.

getActions()

getActions(): Control1[]

Experimental

Gets content of aggregation #getActions actions.

This aggregation describes actions that are added to the chart toolbar. For more information, see sap.ui.mdc.actiontoolbar.ActionToolbarAction. Note: This aggregation is managed by the control, can only be populated during the definition in the XML view, and is not bindable. Any changes of the initial aggregation content might result in undesired effects. Changes of the aggregation have to be made with the sap.ui.mdc.p13n.StateUtil StateUtil.
