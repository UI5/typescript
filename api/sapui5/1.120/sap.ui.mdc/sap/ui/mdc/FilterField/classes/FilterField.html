Class: FilterField

import FilterField from "sap/ui/mdc/FilterField";

Experimental

The FilterField control is used to filter data based on the conditions. The conditions are managed in the corresponding sap.ui.mdc.condition.ConditionModel ConditionModel. That is why the conditions property must be bound to the related conditions in the sap.ui.mdc.condition.ConditionModel ConditionModel. The type of this data must be defined in the dataType property.

Based on the data type settings, a default control is rendered by the FilterField as follows:

 - In display mode, usually a sap.m.Text Text control is rendered.
 - If `multipleLines` is set, an sap.m.ExpandableText ExpandableText control is rendered.
 - If multiple values are allowed, a sap.m.Tokenizer Tokenizer control is rendered.
 - In edit mode, usually an sap.m.Input Input control is rendered.
 - If multiple values are allowed, a sap.m.MultiInput MultiInput control is rendered.
 - If `multipleLines` is set, a sap.m.TextArea TextArea control is rendered.
 - If a date type or a date/time type is used, a sap.m.DateRangeSelection DateRangeSelection
control is rendered.
 - If a date type is used and only single values are allowed, a sap.m.DatePicker DatePicker
control is rendered.
 - If a date type is used and only single ranges are allowed, a sap.m.DateRangeSelection DateRangeSelection
control is rendered.
 - If a date/time type is used and only single values are allowed, a sap.m.DateTimePicker DateTimePicker
control is rendered.
 - If a time type is used and only single values are allowed, a sap.m.TimePicker TimePicker
control is rendered.
 - If used for search, a sap.m.SearchField SearchField control is rendered.
