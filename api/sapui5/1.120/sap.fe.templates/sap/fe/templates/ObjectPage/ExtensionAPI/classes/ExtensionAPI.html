Class: ExtensionAPI

import ExtensionAPI from "sap/fe/templates/ObjectPage/ExtensionAPI";

Extension API for object pages on SAP Fiori elements for OData V4. To correctly integrate your app extension coding with SAP Fiori elements, use only the extensionAPI of SAP Fiori elements. Don't access or manipulate controls, properties, models, or other internal objects created by the SAP Fiori elements framework.
