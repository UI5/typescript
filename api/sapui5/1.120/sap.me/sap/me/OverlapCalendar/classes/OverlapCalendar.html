Class: OverlapCalendar

import OverlapCalendar from "sap/me/OverlapCalendar";

A calendar that allows to display events in a grid and show the overlapped events

Deprecated

(since 1.34.0) - This control was experimental since 1.12. Please use the sap.m.PlanningCalendar instead!
