Class: TabContainer

import TabContainer from "sap/me/TabContainer";

The TabContainer allow to stack 1 to 4 contents in a view with corresponding icons

Deprecated

(since 1.15.0) - The functionality of this control is merged with the sap.m.IconTabBar. Please use the sap.m.IconTabBar instead! This control will not be supported anymore.
