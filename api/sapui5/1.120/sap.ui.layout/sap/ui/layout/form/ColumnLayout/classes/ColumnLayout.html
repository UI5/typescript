Class: ColumnLayout

import ColumnLayout from "sap/ui/layout/form/ColumnLayout";

The ColumnLayout control renders a sap.ui.layout.form.Form Form control in a column-based responsive way. Depending on its size, the sap.ui.layout.form.Form Form control is divided into one or more columns. (XL - max. 4 columns, L - max. 3 columns, M - max. 2 columns and S - 1 column.)

The sap.ui.layout.form.FormContainer FormContainer elements are spread out to the columns depending on the number of sap.ui.layout.form.FormContainer FormContainer elements and their size. For example, if there are 4 columns and 2 sap.ui.layout.form.FormContainer FormContainer elements, each sap.ui.layout.form.FormContainer FormContainer element will use 2 columns. If there are 3 columns and 2 sap.ui.layout.form.FormContainer FormContainer elements, the larger one will use 2 columns, the smaller one 1 column. The size of a sap.ui.layout.form.FormContainer FormContainer element will be determined based on the number of visible sap.ui.layout.form.FormElement FormElement elements assigned to it. If there are more sap.ui.layout.form.FormContainer FormContainer elements than columns, every sap.ui.layout.form.FormContainer FormContainer element uses only one column. So the last row of the sap.ui.layout.form.Form Form control will not be fully used.

The default size of the sap.ui.layout.form.FormContainer FormContainer element can be overwritten by using sap.ui.layout.form.ColumnContainerData ColumnContainerData as LayoutData. If one sap.ui.layout.form.FormContainer FormContainer element has sap.ui.layout.form.ColumnContainerData ColumnContainerData set, the size calculation of the other sap.ui.layout.form.FormContainer FormContainer elements might not lead to the expected result. In this case, use sap.ui.layout.form.ColumnContainerData ColumnContainerData also for the other sap.ui.layout.form.FormContainer FormContainer elements.

The sap.ui.layout.form.FormElement FormElement elements are spread out to the columns of a sap.ui.layout.form.FormContainer FormContainer element arranged in a newspaper-like order. The position of the labels and fields depends on the size of the used column. If there is enough space, the labels are beside the fields, otherwise above the fields.

The default size of a content control of a sap.ui.layout.form.FormElement FormElement element can be overwritten using sap.ui.layout.form.ColumnElementData ColumnElementData as LayoutData. If one control assigned to a sap.ui.layout.form.FormElement FormElement element has sap.ui.layout.form.ColumnElementData ColumnElementData set, the size calculation of the other controls assigned to the sap.ui.layout.form.FormElement FormElement element might not lead to the expected result. In this case, use sap.ui.layout.form.ColumnElementData ColumnElementData for the other controls, assigned to the sap.ui.layout.form.FormElement FormElement element, too.

The placement of the sap.ui.layout.form.FormElement FormElement elements is made by the browser column-count logic. So this can be different in different browsers and lead in some cases to other results than might be expected.

Note: This control cannot be used stand-alone, it just renders a sap.ui.layout.form.Form Form control, so it must be assigned to a sap.ui.layout.form.Form Form control using the layout aggregation.
