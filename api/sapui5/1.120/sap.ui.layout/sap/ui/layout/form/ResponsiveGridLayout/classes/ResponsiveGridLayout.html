Class: ResponsiveGridLayout

import ResponsiveGridLayout from "sap/ui/layout/form/ResponsiveGridLayout";

The ResponsiveGridLayout control renders a sap.ui.layout.form.Form Form using a responsive grid. Internally the sap.ui.layout.Grid Grid control is used for rendering. Using this layout, the sap.ui.layout.form.Form Form is rendered in a responsive way. Depending on the available space, the sap.ui.layout.form.FormContainer FormContainers are rendered in one or different columns and the labels are rendered in the same row as the fields or above the fields. This behavior can be influenced by the properties of this layout control.

On the sap.ui.layout.form.FormContainer FormContainers, labels and content fields, sap.ui.layout.GridGata GridData can be used to change the default rendering. sap.ui.layout.GridGata GridData is not supported for sap.ui.layout.form.FormElement FormElements.

Note: If sap.ui.layout.GridGata GridData is used, this may result in a much more complex layout than the default one. This means that in some cases, the calculation for the other content may not bring the expected result. In such cases, sap.ui.layout.GridGata GridData should be used for all content controls to disable the default behavior.

This control cannot be used stand-alone, it just renders a sap.ui.layout.form.Form Form, so it must be assigned to a sap.ui.layout.form.Form Form using the layout aggregation.

getAdjustLabelSpan()

getAdjustLabelSpan(): boolean

Gets current value of property #getAdjustLabelSpan adjustLabelSpan.

If set, the usage of labelSpanL and labelSpanM are dependent on the number of sap.ui.layout.form.FormContainer FormContainers in one row. If only one sap.ui.layout.form.FormContainer FormContainer is displayed in one row, labelSpanM is used to define the size of the label. This is the same for medium and large Forms. This is done to align the labels on forms where full-size sap.ui.layout.form.FormContainer FormContainers and multiple-column rows are used in the same sap.ui.layout.form.Form Form (because every sap.ui.layout.form.FormContainer FormContainer has its own sap.ui.layout.Grid Grid inside).

If not set, the usage of labelSpanL and labelSpanM are dependent on the sap.ui.layout.form.Form Form size. The number of sap.ui.layout.form.FormContainer FormContainers doesn't matter in this case.

Default value is true.

Returns

getSingleContainerFullSize()

getSingleContainerFullSize(): boolean

Gets current value of property #getSingleContainerFullSize singleContainerFullSize.

If the sap.ui.layout.form.Form Form contains only one single sap.ui.layout.form.FormContainer FormContainer and this property is set, the sap.ui.layout.form.FormContainer FormContainer is displayed using the full size of the sap.ui.layout.form.Form Form. In this case the properties columnsXL, columnsL and columnsM are ignored.

In all other cases the sap.ui.layout.form.FormContainer FormContainer is displayed in the size of one column.

Default value is true.
