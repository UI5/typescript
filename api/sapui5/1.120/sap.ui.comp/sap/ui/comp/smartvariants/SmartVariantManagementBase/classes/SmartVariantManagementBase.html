Class: SmartVariantManagementBase

import SmartVariantManagementBase from "sap/ui/comp/smartvariants/SmartVariantManagementBase";

Overview: The SmartVariantManagementBase control embeds sap.m.VariantManagement VariantManagement control and communicates with the flexibility library that offers SAPUI5 flexibility to manage the variants for the UI Adaptation scenarios.
