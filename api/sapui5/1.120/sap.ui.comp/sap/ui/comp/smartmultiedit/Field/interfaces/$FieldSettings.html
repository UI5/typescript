applyToEmptyOnly?

optional applyToEmptyOnly?: boolean | PropertyBindingInfo | `{${string}}`

Indicates whether to check for an existing value in the data model before applying the changes. Please note that this property does not automatically update the model. It is up to you as the app developer to decide whether you want to consider this property when updating the model or not.
