getGridDataSpan()

getGridDataSpan(): string

Gets current value of property #getGridDataSpan gridDataSpan.

A string type that represents Grid's span values for large, medium and small screens. Allowed values are separated by space Letters L, M or S followed by number of columns from 1 to 12 that the container has to take, for example: "L2 M4 S6", "M12", "s10" or "l4 m4". Note that the parameters has to be provided in the order large medium small. The value set here will be set to all group elements when used with horizontal layout (SmartForm property useHorizontalLayout)

Default value is empty string.

Returns

string

Value of property gridDataSpan

getSingleGroupFullSize()

getSingleGroupFullSize(): boolean

Gets current value of property #getSingleGroupFullSize singleGroupFullSize.

If the SmartForm contains only one single Group and this property is set, the Group is displayed using the full size of the SmartForm. In this case the properties columnsL and columnsM are ignored. In all other cases the Group is displayed in the size of one column.

Default value is true.
