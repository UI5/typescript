Class: SmartMicroChart

import SmartMicroChart from "sap/ui/comp/smartmicrochart/SmartMicroChart";

The SmartMicroChart control creates a chart based on OData metadata and the configuration specified by mSettings. The entitySet property is required. This property is used to fetch metadata and annotation information from the specified default OData model. Depending on the UI/ChartType annotation, the control creates a corresponding sap.ui.comp.smartmicrochart.SmartAreaMicroChart SmartAreaMicroChart, sap.ui.comp.smartmicrochart.SmartBulletMicroChart SmartBulletMicroChart, sap.ui.comp.smartmicrochart.SmartStackedBarMicroChart SmartStackedBarMicroChart, sap.ui.comp.smartmicrochart.SmartLineMicroChart SmartLineMicroChart, or sap.ui.comp.smartmicrochart.SmartRadialMicroChart SmartRadialMicroChart instance and delegates it to the internal control. Note: Most of the attributes are not dynamic and cannot be changed once the control has been initialized.
