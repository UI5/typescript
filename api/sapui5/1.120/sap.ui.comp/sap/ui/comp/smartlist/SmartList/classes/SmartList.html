Class: SmartList

import SmartList from "sap/ui/comp/smartlist/SmartList";

A smart control to simplify using the sap.m.List and sap.m.Tree controls in list patterns. Overview: The SmartList control creates a list or tree based on the configuration specified. There is, however, a difference to other smart controls: This control does not use annotations to automatically create its content. Hence, a template must always be provided for this control. Structure: The SmartList control consists of the following elements: - OverflowToolbar control: Displays the header and other action buttons. Users can add their own toolbar and buttons in the view. - List or Tree control: The actual list/tree control. Users can also add this in the view with the required configuration. The entitySet property must be specified to use the control. This attribute is used to fetch the actual data. The listItemTemplate aggregation must also be specified with the required item template, such as StandardListItem/StandardTreeItem, which will be used during binding. Note:: Most of the attributes/properties are not dynamic and cannot be changed once the control has been initialized.
