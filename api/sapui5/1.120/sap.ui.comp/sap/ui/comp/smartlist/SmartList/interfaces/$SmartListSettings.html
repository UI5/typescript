showRowCount?

optional showRowCount?: boolean | PropertyBindingInfo | `{${string}}`

The number of rows is shown along with the header text if the property showRowCount is set to true.

Note: - To improve your application's performance, activate the inline count for OData bindings to avoid sending dedicated OData requests. - If no stable overall count can be retrieved from the binding, the count will not be displayed. This is currently the case for TreeBinding or if no count is requested by the binding.
