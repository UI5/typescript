Call Signature

attachChange(oData, fnFunction, oListener?): this

Attaches event handler fnFunction to the #event:change change event of this sap.suite.ui.commons.DateRangeSliderInternal.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.suite.ui.commons.DateRangeSliderInternal itself.

This event is fired when user changes the positions of the grips of the control. It contains value as Date object and value2 as Date object which are based on the positions of two grips.
