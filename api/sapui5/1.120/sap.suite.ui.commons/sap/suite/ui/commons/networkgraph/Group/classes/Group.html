getMinWidth()

getMinWidth(): number

Gets current value of property #getMinWidth minWidth.

Minimal width of the group (swim lane) for the SwimLanes type of sap.suite.ui.commons.networkgraph.LayoutRenderType. If not specified, the width of the group (swim lane) is defined automatically, based on the width of the nodes included in the swim lane. If the width specified in this property is too small to fit the nodes included in this group (swim lane), the width is increased accordingly.

Default value is undefined.
