userAction?

optional userAction?: boolean

Indicates whether the selection was triggered by a user action or in any other way. Set to true if the selection was triggered by a user action, for example, by clicking with a mouse or pressing the Enter key. Set to false if the selection was triggered in a different way, for example, by shifting focus back from a Popover element or by pressing an arrow key. For backward compatibility, the select event is fired whenever an item gets focus.
