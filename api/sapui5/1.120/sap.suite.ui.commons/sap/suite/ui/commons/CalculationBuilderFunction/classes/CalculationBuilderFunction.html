Class: CalculationBuilderFunction

import CalculationBuilderFunction from "sap/suite/ui/commons/CalculationBuilderFunction";

A custom function to be used in the calculation builder. The default functions available for the calculation builder are defined in sap.suite.ui.commons.CalculationBuilderFunctionType.
