Class: UnifiedThingInspector

import UnifiedThingInspector from "sap/suite/ui/commons/UnifiedThingInspector";

This control provides an ability to display a thing (for example, object factsheet) on the desktop, tablet, and phone devices in a Fiori style.

Deprecated

(since 1.32) - Deprecated. Object page should be used instead.
