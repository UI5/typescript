Class: MicroProcessFlow

import MicroProcessFlow from "sap/suite/ui/commons/MicroProcessFlow";

The MicroProcessFlow control can be used to track the progress of a process. It is best used for linear processes, such as document, order, and approval flows, and can be embedded in tiles, tables, and other containers.

To display more complex processes and workflows, use sap.suite.ui.commons.ProcessFlow instead.
