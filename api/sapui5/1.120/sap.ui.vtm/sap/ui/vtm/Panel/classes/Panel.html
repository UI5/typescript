Class: Panel

import Panel from "sap/ui/vtm/Panel";

Experimental

A control that represents a VTM panel. Contains: - A header area containing a title and optionally a set of application controls - A sap.ui.vtm.Tree and a sap.ui.vtm.Viewport separated by a splitter

Deprecated

(since 1.96.10) - because it is part of the deprecated package sap.ui.vtm (since 1.50.0) - This class is experimental and might be modified or removed in future versions.
