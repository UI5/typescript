Representation of a recursive hierarchy.

Constructor

new RecursiveHierarchy(oEntityType, oNodeIDProperty, oParentNodeIDProperty, oNodeLevelProperty, oNodeValueProperty, oNodeExternalKeyProperty): RecursiveHierarchy

Create a representation of a recursive hierarchy defined on one multiple properties in an OData entity type query. Do not create your own instances.

oNodeExternalKeyProperty

object

datajs object for the property holding the node external key of the hierarchy node. The external key is a human-readable identification of a node. The value of the hierarchy-node-external-key-for attribute is always the name of another property in the same type. It points to the related property holding the hierarchy node ID.
