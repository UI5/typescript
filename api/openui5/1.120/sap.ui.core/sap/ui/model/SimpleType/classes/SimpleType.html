Abstract Class: SimpleType

import SimpleType from "sap/ui/model/SimpleType";

This is an abstract base class for simple types. A simple type can format a raw model value based on the given format options, parse an external value based on the given format options and validate the raw model value based on the given constraints. An implementation of a simple type needs to implement #formatValue, #parseValue and #validateValue. If the raw value, which is the value in model representation, isn't already a JavaScript primitive type, subclasses must override #getModelFormat.

getModelFormat()

getModelFormat(): object

Returns an object with format and parse methods. format converts the internal value which has a JavaScript primitive type or is a built-in object such as Date which can be used by a control to the raw value, and parse converts the raw value to the internal value.

You may return an instance of sap.ui.core.format.DateFormat DateFormat or sap.ui.core.format.NumberFormat NumberFormat.

The default implementation of the format and parse methods simply returns the given parameter. Subclasses of sap.ui.model.SimpleType#constructor SimpleType should override this method if the raw value isn't already a JavaScript primitive type. The overwritten method must return an object which has the format and parse methods implemented.

Example: If the type is related to a JavaScript Date object, but the raw value isn't, this method should return an instance of sap.ui.core.format.DateFormat DateFormat, which is able to convert between the raw value and a JavaScript Date object.
