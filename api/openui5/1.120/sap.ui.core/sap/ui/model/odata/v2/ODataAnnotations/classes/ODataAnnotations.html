Methods

addSource()

addSource(vSource): Promise<any>

Adds one or several sources to the annotation loader. Sources will be loaded instantly but merged only after the previously added source has either been successfully merged or failed.

Parameters

vSource

string | string[] | Source | Source[]

One or several Annotation source or array of annotation sources; an annotation source is either a string containing a URL or an object of type sap.ui.model.odata.v2.ODataAnnotations.Source.

Returns

Promise<any>

The promise to (load,) parse and merge the given source(s). The Promise resolves with an array of maps containing the properties source and data; see the parameters of the success event for more details. In case at least one source could not be (loaded,) parsed or merged, the promise fails with an array of objects containing Errors and/or Success objects.

attachAllFailed()

Call Signature

attachAllFailed(oData, fnFunction, oListener?): this

Attaches the given callback to the allFailed event.

This event exists for compatibility with the old Annotation loader. It is fired when no annotation from a group of sources was successfully (loaded,) parsed and merged. The parameter result will be set on the event argument and contains an array of Errors in the order in which the sources had been added.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.ui.model.odata.v2.ODataAnnotations itself.

attachError(oData, fnFunction, oListener?): this

Attaches the given callback to the #event:error error event, which is fired whenever a source cannot be loaded, parsed or merged into the annotation data.

The following parameters will be set on the event object that is given to the callback function: source

  • A map containing the properties type - containing either "url" or "xml" - and data containing the data given as source, either a URL or an XML string depending on how the source was added. error - An Error object describing the problem that occurred

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.ui.model.odata.v2.ODataAnnotations itself.

setHeaders()

setHeaders(mHeaders): void

Set custom headers which are provided in a key/value map. These headers are used for all requests. The "Accept-Language" header cannot be modified and is set using the core's language setting.

To remove these headers, simply set the mHeaders parameter to {}. Note that when calling this method again, all previous custom headers are removed, unless they are specified again in the mCustomHeaders parameter.
