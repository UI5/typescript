reason?

optional reason?: ChangeReason

The reason for the 'refresh' event could be sap.ui.model.ChangeReason.Context Context when the binding's parent context is changed, sap.ui.model.ChangeReason.Filter Filter on #filter and #setAggregation, sap.ui.model.ChangeReason.Refresh Refresh on #refresh, or when the binding is initialized, sap.ui.model.ChangeReason.Sort Sort on #sort. #changeParameters leads to sap.ui.model.ChangeReason.Filter Filter if one of the parameters '$filter' and '$search' is changed, otherwise it leads to sap.ui.model.ChangeReason.Sort Sort if the parameter '$orderby' is changed; in other cases, it leads to sap.ui.model.ChangeReason.Change Change. If APIs that would normally fire change events have been called while the binding is suspended, #resume leads to the "strongest" change reason in the order sap.ui.model.ChangeReason.Filter Filter, sap.ui.model.ChangeReason.Sort Sort, sap.ui.model.ChangeReason.Refresh Refresh, sap.ui.model.ChangeReason.Change Change.
