optional deprecated?: boolean

Flag that marks the event as deprecated (defaults to false). May lead to an additional warning log message at runtime when the event is still used. For the documentation, also add a @deprecated tag in the JSDoc, describing since when it is deprecated and what any alternatives are.

enableEventBubbling?

optional enableEventBubbling?: boolean

whether event bubbling is enabled on this event. When true the event is also forwarded to the parent(s) of the object (see sap.ui.base.EventProvider#getEventingParent) until the bubbling of the event is stopped or no parent is available anymore.
