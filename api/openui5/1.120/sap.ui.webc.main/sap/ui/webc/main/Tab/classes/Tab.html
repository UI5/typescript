Class: Tab

import Tab from "sap/ui/webc/main/Tab";

Experimental

The sap.ui.webc.main.Tab represents a selectable item inside a sap.ui.webc.main.TabContainer. It defines both the item in the tab strip (top part of the sap.ui.webc.main.TabContainer) and the content that is presented to the user once the tab is selected.

Since

1.92.0

Deprecated

(since 1.120) - this Web Components consumption model has been discarded. Until an alternative Web Components consumption model is available in the future, use sap.m and sap.f controls with similar functionality. (since 1.92.0) - This control is experimental and its API might change significantly.
