Class: BreadCrumbs

import BreadCrumbs from "sap/uxap/BreadCrumbs";

Represents the navigation steps up to the current location in the app.

Overview:

The BreadCrumbs control allows the users to quickly navigate to a previous location on the path that got them to the current location by choosing the displayed navigation steps.

It has two main modes of operation: - A trail of links followed by separators, when there's enough space for the control to fit on one line. - A dropdown list with the links, when the trail of links wouldn't fit on one line.
