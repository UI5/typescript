Class: PlanningCalendarLegend

import PlanningCalendarLegend from "sap/m/PlanningCalendarLegend";

A legend for the sap.m.PlanningCalendar that displays the special dates and appointments in colors with their corresponding description. The PlanningCalendarLegend extends sap.ui.unified.CalendarLegend and overwrites the default value for property columnWidth to auto
