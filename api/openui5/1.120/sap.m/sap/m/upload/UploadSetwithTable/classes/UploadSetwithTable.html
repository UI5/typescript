Class: UploadSetwithTable

import UploadSetwithTable from "sap/m/upload/UploadSetwithTable";

Experimental

This control allows you to upload one or more files from your device, such as desktop, tablet or phone, and attach them to your application in a responsive tabular manner. This control builds on the sap.m.upload.UploadSet UploadSet control. Provides flexibility to tailor the design of the table including columns, cells and the content to suit specific requirements.

To render the sap.m.upload.UploadSetwithTablecontrol properly, the order of the columns aggregation should match the order of the cells aggregation (sap.m.upload.UploadSetwithTableItem).

Note: Control recommends to use sap.m.upload.Column with the columns aggregation. sap.m.upload.Column control is built on sap.m.Column (sap.m.Column Column) control and provides ability to define personalization specific properties for column and is essential to setup personalization for the sap.m.upload.UploadSetwithTable control.
