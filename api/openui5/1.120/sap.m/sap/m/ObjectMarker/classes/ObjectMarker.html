Class: ObjectMarker

import ObjectMarker from "sap/m/ObjectMarker";

The sap.m.ObjectMarker control represents one of the following predefined types: Flagged Favorite Draft Locked LockedBy Unsaved UnsavedBy Note: Use the LockedBy/UnsavedBy type along with the additionalInfo property to display the name of the user who locked/changed the object. If additionalInfo property is not set when using LockedBy/UnsavedBy types, the string "Locked by another user"/"Unsaved changes by another user" will be displayed. If you don't want to display name of the user, simply use the Locked/Unsaved types.
