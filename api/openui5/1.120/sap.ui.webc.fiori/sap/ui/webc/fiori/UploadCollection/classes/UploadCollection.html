Class: UploadCollection

import UploadCollection from "sap/ui/webc/fiori/UploadCollection";

Experimental

Overview: This component allows you to represent files before uploading them to a server, with the help of sap.ui.webc.fiori.UploadCollectionItem. It also allows you to show already uploaded files.

Since

1.92.0

Deprecated

(since 1.120) - this Web Components consumption model has been discarded. Until an alternative Web Components consumption model is available in the future, use sap.m and sap.f controls with similar functionality. (since 1.92.0) - This control is experimental and its API might change significantly.
