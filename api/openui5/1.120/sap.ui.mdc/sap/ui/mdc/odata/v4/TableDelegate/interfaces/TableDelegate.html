Methods

updateBinding()

updateBinding(oTable, oBindingInfo, oBinding?, mSettings?): void

Updates the row binding of the table if possible, rebinds otherwise.

Compares the current and previous state of the table to detect whether rebinding is necessary or not. The diffing happens for the sorters, filters, aggregation, parameters, and the path of the binding. Other sap.ui.base.ManagedObject.AggregationBindingInfo binding info keys like events, model... must be provided in the #updateBindingInfo updateBindingInfo method always, and those keys must not be changed conditionally.
