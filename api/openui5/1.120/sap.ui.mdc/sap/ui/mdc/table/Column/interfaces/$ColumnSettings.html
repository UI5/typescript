importance?

optional importance?: PropertyBindingInfo | `{${string}}` | "None" | "Medium" | Priority | "High" | "Low"

Defines the column importance.

The column importance is taken into consideration for calculating the minScreenWidth property and for setting the demandPopin property of the column. See sap.m.Table#getAutoPopinMode for more details, which is automatically set to true.

Deprecated

(since 1.110) - replaced with sap.ui.mdc.table.ResponsiveColumnSettings#importance

This property will be ignored whenever the sap.ui.mdc.table.ResponsiveColumnSettings are applied to the column.

required?

optional required?: boolean | PropertyBindingInfo | `{${string}}`

Indicates whether the content of the column is required. Note: The table only takes care of announcing the state of the column header as defined by the required property. The application needs to take care of the screen reader announcement of the state of the table cells, for example, by setting the required property to true for sap.m.Input.
