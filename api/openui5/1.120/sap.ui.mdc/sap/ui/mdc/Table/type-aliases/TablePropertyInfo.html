Type Alias: TablePropertyInfo

import { TablePropertyInfo } from "sap/ui/mdc/Table";

TablePropertyInfo = PropertyInfo & object

An object literal describing a data property in the context of a sap.ui.mdc.Table with module:sap/ui/mdc/odata/v4/TableDelegate.

When specifying the PropertyInfo objects in the sap.ui.mdc.Table#getPropertyInfo propertyInfo property, the following attributes need to be specified: - name - path - dataType - formatOptions - constraints - maxConditions - caseSensitive - visualSettings.widthCalculation - propertyInfos - groupable - key - unit - text - aggregatable - extension.technicallyGroupable - extension.technicallyAggregatable - extension.customAggregate - extension.customAggregate.contextDefiningProperties

If the property is complex, the following attributes need to be specified: - name - visualSettings.widthCalculation - propertyInfos (all referenced properties must be specified)

extension.customAggregate?

optional customAggregate?: object

Provide an object, it can be empty, if there is a CustomAggregate whose Qualifier is equal to the name of this property. This enables the option to show totals if aggregatable is true.

extension.customAggregate.contextDefiningProperties?

optional contextDefiningProperties?: string[]

A list of related properties (by name) that are the context-defining properties of the CustomAggregate.

extension.technicallyAggregatable?

optional technicallyAggregatable?: boolean

If aggregatable is set to false to exclude it from aggregate personalization on the UI, the UI still needs to know that this property is aggregatable for data requests.

extension.technicallyGroupable?

optional technicallyGroupable?: boolean

If groupable is set to false to exclude it from group personalization on the UI, the UI still needs to know that this property is groupable for data requests.
