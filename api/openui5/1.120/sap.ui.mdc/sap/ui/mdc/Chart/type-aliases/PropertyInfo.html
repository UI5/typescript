Type Alias: PropertyInfo

import { PropertyInfo } from "sap/ui/mdc/Chart";

PropertyInfo = object

An object literal describing a data property in the context of a sap.ui.mdc.Chart.

When specifying the PropertyInfo objects in the sap.ui.mdc.Chart#getPropertyInfo propertyInfo property, the following attributes need to be specified: - label - propertyPath
