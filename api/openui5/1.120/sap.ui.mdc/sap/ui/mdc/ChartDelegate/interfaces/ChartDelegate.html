Interface: ChartDelegate

import ChartDelegate from "sap/ui/mdc/ChartDelegate";

Base Delegate for sap.ui.mdc.Chart Chart. Extend this object in your project to use all functionalities of the sap.ui.mdc.Chart Chart. This class provides method calls, that are called by the Chart for specific operations and overwrite the internal behavior.
