Class: FilterBar

import FilterBar from "sap/ui/mdc/FilterBar";

Experimental

The FilterBar control is used to display filter attributes in a user-friendly manner to populate values for a query. The filters are arranged in a logical row that is divided depending on the space available and the width of the filters. The Go button fires the search event, and the Adapt Filters button shows the filter dialog. The FilterBar control creates and handles the filters based on the provided metadata information. The metadata information is provided via the sap.ui.mdc.FilterBarDelegate FilterBarDelegate implementation. This implementation has to be provided by the application.
