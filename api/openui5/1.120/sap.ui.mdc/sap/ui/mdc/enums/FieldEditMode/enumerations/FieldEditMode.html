Enumeration: FieldEditMode

Defines in what mode a sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField or sap.ui.mdc.MultiValueField MultiValueField is rendered.

Since

1.115

Enumeration Members

Disabled

Disabled: "Disabled"

sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField or sap.ui.mdc.MultiValueField MultiValueField is rendered in disabled mode

Display: "Display"

sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField or sap.ui.mdc.MultiValueField MultiValueField is rendered in display mode

Editable

Editable: "Editable"

sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField or sap.ui.mdc.MultiValueField MultiValueField is rendered in editable mode

EditableDisplay

EditableDisplay: "EditableDisplay"

If more than one control is rendered by the sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField or sap.ui.mdc.MultiValueField MultiValueField control, the first part is editable, and the other parts are in display mode.

EditableReadOnly

EditableReadOnly: "EditableReadOnly"

If more than one control is rendered by the sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField or sap.ui.mdc.MultiValueField MultiValueField control, the first part is editable, and the other parts are read-only.
