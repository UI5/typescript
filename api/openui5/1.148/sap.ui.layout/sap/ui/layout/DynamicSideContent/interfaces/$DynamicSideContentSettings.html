containerQuery?

optional containerQuery?: boolean | PropertyBindingInfo | `{${string}}`

If set to true, then not the media Query (device screen size) but the size of the container, surrounding the control, defines the current range.

equalSplit?

optional equalSplit?: boolean | PropertyBindingInfo | `{${string}}`

Defines whether the control is in equal split mode. In this mode, the side and the main content take 50:50 percent of the container on all screen sizes except for phone, where the main and side contents are switching visibility using the toggle method.

Note: setting this property overrides values set in sideContentWidthM, sideContentWidthL, sideContentWidthXL.

sideContentWidthL?

optional sideContentWidthL?: string | PropertyBindingInfo

Sets the width of the side content for L breakpoint (screen width <= 1440 px and > 1024px).

Setting value to this property overrides the default width of the side content container in L breakpoint, except when an equalSplit property is set. The width of the main content container is calculated respectively.
