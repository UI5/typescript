Class: FormContainer

import FormContainer from "sap/ui/layout/form/FormContainer";

A FormContainer represents a group inside a sap.ui.layout.form.Form Form. It consists of sap.ui.layout.form.FormElement FormElements. The rendering of the FormContainer is done by the sap.ui.layout.form.Form#getLayout FormLayout assigned to the sap.ui.layout.form.Form Form.

getTitle()

getTitle(): string | Title

Gets content of aggregation #getTitle title.

Title of the FormContainer. Can either be a Title element or a string. If a Title element is used, the style of the title can be set.

Note: If a #getToolbar Toolbar is used, the Title is ignored.

Note: If the title is provided as a string, the title is rendered with a theme-dependent default level. As the Form control cannot know the structure of the page, this might not fit the page structure. In this case provide the title using a Title element and set its sap.ui.core.Title#setLevel level to the needed value.

Note: Do not use sap.ui.core.Title#setIcon icon for sap.ui.core.Title Title. If an icon is needed, use a #setToolbar Toolbar to show both title and icon.

Note: Do not use sap.ui.core.Title#setEmphasized emphasized for sap.ui.core.Title Title. This is not supported in current themes and might lead to accessibillity issues.

Returns

string | Title

getToolbar()

getToolbar(): Toolbar

Gets content of aggregation #getToolbar toolbar.

Toolbar of the FormContainer.

Note: If a Toolbar is used, the #getTitle Title is ignored. If a title is needed inside the Toolbar it must be added at content to the Toolbar. In this case add the Title to the #addAriaLabelledBy ariaLabelledBy association. Use the right title level to meet the visual requirements. This might be theme-dependent.

Returns

Toolbar
