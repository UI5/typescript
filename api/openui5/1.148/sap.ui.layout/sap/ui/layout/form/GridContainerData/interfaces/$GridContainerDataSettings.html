Describes the settings that can be provided to the GridContainerData constructor.

Deprecated

As of version 1.67.0. as sap.ui.commons library is deprecated and the GridLayout must not be used in responsive applications. Please use ResponsiveGridLayout or ColumnLayout instead.

Properties

halfGrid?

optional halfGrid?: boolean | PropertyBindingInfo | `{${string}}`

If set, the container takes half the width of the Form (8 cells), if not it takes the full width (16 cells). If the GridLayout is set to singleColumn, the full width of the grid is only 8 cells. So containers are rendered only once per row.
