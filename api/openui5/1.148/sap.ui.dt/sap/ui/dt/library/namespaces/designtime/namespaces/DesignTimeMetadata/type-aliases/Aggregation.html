childNames?

optional childNames?: { plural: string | Function; singular: string | Function; } | Function

Provide or compute name for the controls inside the aggregation which is understandable for the key user. This is needed for the "addODataProperty" and "createContainer" action to show the names in the context menu (Add , Available ). Name the control based on the general UI concept and follow the guidance from https://experience.sap.com/fiori-design/. The key user doesn't care about the difference between a smart, mobile, or responsive version of a form, it's just a form.

Function

domRef?

optional domRef?: string | Function

Defines the DOM reference of the aggregation. The DOM reference is used to calculate the dimension of the aggregation at design time. This is needed, for instance, to make drag&drop possible. If no domRef property is given, a heuristic is used to calculate the dimension of the aggregation from its children during the design time.

ignore?

optional ignore?: boolean | Function

Used to ignore the aggregation (and all its children) at design time. For example, this can be used to ignore deprecated or duplicated aggregations as well as aggregations irrelevant during the design time (such as dependents). If the value is true, then no overlays will be created for the aggregation and its children. For more options on how to disable actions in design time please refer to the UI5 Demo Kit.

propagateMetadata?

optional propagateMetadata?: Function

Returns DesignTime-Metadata object which extends or overrides existing metadata of a successor control. In the negative case it returns the boolean "false" value. The propagateMetadata function gets 2 parameters passed through during execution: oControl and oRelevantContainerControl. The second parameter is the control which has defined this propagation function. It can be used if you need to know the relevantContainer during the execution of the function.

propagateRelevantContainer?

optional propagateRelevantContainer?: boolean | Function

Defines the relevant container control for the actions which belong to successor controls.
