Properties

aggregationLike

aggregationLike: boolean

Can be used to tell the design time that it should follow the association hierarchy. This is used by controls like e.g. the componentContainer that should allow to follow the association component, which defines the control hierarchy but is not a real aggregation (more isolation, regarding model propagation/rendering/eventing/...).
