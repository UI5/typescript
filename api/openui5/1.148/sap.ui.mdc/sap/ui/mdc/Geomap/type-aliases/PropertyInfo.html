PropertyInfo = PropertyInfo & object

Experimental

An object literal describing a data property in the context of a sap.ui.mdc.Geomap.

When specifying the PropertyInfo objects in the sap.ui.mdc.Geomap#getPropertyInfo propertyInfo property, the following attributes need to be specified: - key - label - visible - path - dataType - formatOptions - constraints
