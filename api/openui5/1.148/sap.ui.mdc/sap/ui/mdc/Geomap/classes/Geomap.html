Class: Geomap

import Geomap from "sap/ui/mdc/Geomap";

Experimental

The Geomap control creates a geomap based on metadata and the configuration specified. Note: The geomap needs to be created inside the GeomapDelegate.

Attaches event handler fnFunction to the #event:zoomChange zoomChange event of this sap.ui.mdc.Geomap.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.ui.mdc.Geomap itself.
