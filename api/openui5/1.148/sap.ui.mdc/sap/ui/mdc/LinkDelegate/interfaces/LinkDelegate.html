fetchLinkType()

fetchLinkType(oLink): Promise<LinkTypeWrapper>

Calculates and returns the type of link that is displayed. By default, this method returns a Promise that resolves into a sap.ui.mdc.link.LinkTypeWrapper LinkTypeWrapper. The sap.ui.mdc.link.LinkTypeWrapper LinkTypeWrapper contains an initialType and a runtimeType sap.ui.mdc.link.LinkType LinkType. The initialType has a type property of type Popover and a directLink property of type undefined. The runtimeType is of type null.

Parameters

oLink

Link

Instance of the Link

Returns

Promise<LinkTypeWrapper>

Once resolved, a sap.ui.mdc.link.LinkTypeWrapper containing an initial sap.ui.mdc.link.LinkType and an optional Promise are returned. The optional Promise also returns a sap.ui.mdc.link.LinkType object. Once the optional Promise has been resolved, the returned sap.ui.mdc.link.LinkType overwrites the initialType.
