import { State } from "sap/ui/mdc/library";

State = object

The State object describes the interface to apply and retrieve the current adaptation state from mdc controls. The sap.ui.mdc.p13n.StateUtil StateUtil class can be used to programatically apply changes considered for the controls personalization to be part of its persistence.
