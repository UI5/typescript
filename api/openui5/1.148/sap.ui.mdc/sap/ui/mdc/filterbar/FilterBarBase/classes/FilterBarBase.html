### getFilterItems()

> **getFilterItems**(): [`FilterField`](../../../FilterField/classes/FilterField.html)[]

Gets content of aggregation #getFilterItems filterItems.

Contains all the displayed sap.ui.mdc.FilterField filter fields of the `FilterBarBase` control.

**Note:** This aggregation is managed by the control, can only be populated during the definition in
the XML view, and is not bindable. Any changes of the initial aggregation content might result in undesired
effects. Changes of the aggregation have to be made with the sap.ui.mdc.p13n.StateUtil StateUtil.
Also, the `conditions` property of `filterItems` is managed by the control.
