getFirstMatch()

getFirstMatch(oValueHelp, oContent, oConfig): Context

Returns the content that is used for the autocomplete feature and for user input, if the entered text leads to more than one filter result.

By default, this method searches and returns an entry from a set of relevant contexts of the given sap.ui.mdc.valuehelp.base.ListContent ListContent.

To determine which columns are relevant for the search, the currently active displayMode sap.ui.mdc.enums.FieldDisplay Display of the connected control will be used. While a Value configuration will lead to a 'key'-only search, DescriptionValue leads to searching the description first and the key afterwards. Other modes work the same way.

For each relevant column all items are searched for an exact match first and again with a startsWith filter afterwards, if necessary.

If the caseSensitive property is disabled, whichever entry comes first, wins, whether the user's input is in lowercase or uppercase letters.

retrieveContent()

retrieveContent(oValueHelp, oContainer, sContentId): Promise<any>

Requests additional content for the value help.

This method is called during the opening phase of a ValueHelp, if a new content is displayed for a CollectiveSearch dialog or if one of the following methods is called: sap.ui.mdc.ValueHelp#getItemForValue getItemForValue, sap.ui.mdc.ValueHelp#requestShowTypeahead requestShowTypeahead, sap.ui.mdc.ValueHelp#requestShowValueHelp requestShowValueHelp

So depending on the value help sap.ui.mdc.valuehelp.base.Content Content used, all content controls and data need to be assigned. Once they are assigned and the data is set, the returned Promise needs to be resolved. Only then does the value help continue opening or reading data. By default, this method returns a Promise that resolves into undefined.
