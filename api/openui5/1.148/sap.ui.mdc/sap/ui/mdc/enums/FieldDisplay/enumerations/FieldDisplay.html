Enumeration: FieldDisplay

Defines the output of a sap.ui.mdc.Field Field, sap.ui.mdc.FilterField FilterField, or sap.ui.mdc.MultiValueField MultiValueField control.

For the sap.ui.mdc.Field Field control, this enumeration defines how the value and additionalValue properties are formatted.

For the sap.ui.mdc.MultiValueField MultiValueField control, this enumeration defines how the key and description properties of the items are formatted.

For the sap.ui.mdc.FilterField FilterField control, this enumeration defines how key and description of equal conditions are formatted.
