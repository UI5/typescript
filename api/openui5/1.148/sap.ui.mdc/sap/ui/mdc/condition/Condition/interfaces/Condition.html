Interface: Condition

import Condition from "sap/ui/mdc/condition/Condition";

Utilities to create conditions to be used in sap.ui.mdc.FilterField FilterField or sap.ui.mdc.FilterBar FilterBar.

Since

1.61.0

Methods

createCondition()

Call Signature

createCondition(sOperator, aValues, oInParameters, oOutParameters, sValidated, oPayload?): ConditionObject

Creates a condition object.

Parameters
sOperator

string

Operator for the condition. The standard operators can are mentioned in sap.ui.mdc.enums.OperatorName OperatorName.

aValues

any[]

Array of values for the condition

oInParameters

object

In parameters of the condition. (Do not use it for new conditions, use payload instead.)

oOutParameters

object

Out parameters of the condition. (Do not use it for new conditions, use payload instead.)

sValidated

ConditionValidated | "NotValidated" | "Validated"

If set to ConditionValidated.Validated, the condition is validated (by the value help) and not shown in the sap.ui.mdc.valuehelp.content.Conditions Conditions content

oPayload?

object

Payload of the condition

Returns

ConditionObject

The new condition object with the given operator and values

createItemCondition()

createItemCondition(vKey, sDescription, oInParameters?, oOutParameters?, oPayload?): ConditionObject

Creates a condition instance for a condition representing a item chosen from the value help.

This is a "equal to" (EQ) condition with key and description. It is used for entries selected in the field help and for everything entered in the sap.ui.mdc.Field Field control.

Parameters

vKey

any

Key value for the condition

sDescription

string

Description of the operator

oInParameters?

object

In parameters of the condition. (Do not use it for new conditions, use payload instead.)

oOutParameters?

object

Out parameters of the condition. (Do not use it for new conditions, use payload instead.)

oPayload?

object

Payload of the condition

Returns

ConditionObject

The new condition object with the EQ operator along with sKey and sDescription as aValues
