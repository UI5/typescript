Class: Header

import Header from "sap/f/cards/Header";

Displays general information in the header of the sap.f.Card.

You can configure the title, subtitle, status text and icon, using the provided properties.

Notes: - You should always set a title. - To show a KPI or any numeric information, use sap.f.cards.NumericHeader instead.
