Class: VariantManagement

import VariantManagement from "sap/m/VariantManagement";

Can be used to manage variants. You can use this control to create and maintain personalization changes. The persistency and retrieval of such changes has to be handled by the hosting application. Note: On the user interface, variants are generally referred to as "views".
