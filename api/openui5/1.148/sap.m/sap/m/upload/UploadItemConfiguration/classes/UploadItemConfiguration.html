Class: UploadItemConfiguration

import UploadItemConfiguration from "sap/m/upload/UploadItemConfiguration";

sap.m.UploadItemConfiguration represents the configuration for the items in the sap.m.plugins.UploadSetwithTable UploadSetwithTable plugin. The configuration template represents the paths in the model to the file name, mediaType, url, uploadUrl, previewable, and file size properties in reference to the sap.m.upload.UploadItem UploadItem. This is essential for the plugin in understanding the structure of the model data bound to continue with operations. Note: Configuration is mandatory for the plugin to offer the features such as file preview, download, rename etc. The element must be used only within the sap.m.plugins.UploadSetwithTable UploadSetwithTable plugin.
