Class: ToolbarLayoutData

import ToolbarLayoutData from "sap/m/ToolbarLayoutData";

Defines layout data for the sap.m.Toolbar items.

Note: The sap.m.ToolbarSpacer is a flex control that is intended to control its own behavior, thus sap.m.ToolbarLayoutData is not supported as value for the layoutData aggregation of sap.m.ToolbarSpacer and if set it's ignored.

getShrinkable()

getShrinkable(): boolean

Gets current value of property #getShrinkable shrinkable.

Determines whether the control, when in a toolbar, is shrinkable or not. For controls with fixed width (100px, 5rem, etc...) this property is ignored.

Notes: - Nested layout controls should not be shrinkable. - This property has no effect on sap.m.Breadcrumbs as it is shrinkable by default.

Default value is false.

boolean
