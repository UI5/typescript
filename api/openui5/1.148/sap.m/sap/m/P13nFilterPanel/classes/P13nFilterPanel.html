Class: P13nFilterPanel

import P13nFilterPanel from "sap/m/P13nFilterPanel";

The P13nFilterPanel control is used to define filter-specific settings for table personalization.

Since

1.26.0

Deprecated

As of version 1.124. replaced by the artifacts in sap.m.p13n.
