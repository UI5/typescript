Class: FormattedText

import FormattedText from "sap/m/FormattedText";

The FormattedText control allows the usage of a limited set of tags for inline display of formatted text in HTML format.

getHtmlText()

getHtmlText(): string

Gets current value of property #getHtmlText htmlText.

Text in HTML format. The following tags are supported: - a - abbr - bdi - blockquote - br - cite - code - em - h1 - h2 - h3 - h4 - h5 - h6 - p - pre - strong - span - u - s - dl - dt - dd - ul - ol - li style, dir and target attributes are allowed. If target is not set, links open in a new window by default. Only safe href attributes can be used. See module:sap/base/security/URLListValidator URLListValidator.

Note: Keep in mind that not supported HTML tags and the content nested inside them are both not rendered by the control.

Default value is empty string.

Returns

string

Value of property htmlText

getTextDirection(): TextDirection

Defines the directionality of the text in the FormattedText, e.g. right-to-left(RTL) or left-to-right (LTR).
