Interface: IContent

import { IContent } from "sap/m/library/namespaces/p13n";

Interface for P13nPopup which are suitable as content for the sap.m.p13n.Popup. Implementation of this interface should include the following methods:

 - `getTitle`

Implementation of this interface can optionally provide the following methods:

 - `getVerticalScrolling`
 - `onReset`

Since

1.97
