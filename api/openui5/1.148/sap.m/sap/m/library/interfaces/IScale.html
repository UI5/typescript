Interface: IScale

import { IScale } from "sap/m/library";

Interface for controls which are suitable as a Scale for the Slider/RangeSlider. Implementation of this interface should implement the following methods: - getTickmarksBetweenLabels - calcNumberOfTickmarks - handleResize - getLabel

calcNumberOfTickmarks()

calcNumberOfTickmarks(fSize, fStep, iTickmarksThreshold): number

Returns how many tickmarks would be drawn on the screen. The start and the end tickmark should be specified in this method.

number

Size of the scale. This is the distance between the start and end point i.e. 0..100

getLabel()?

optional getLabel(fValue, oSlider): string | number

Provides a custom tickmark label.

This method is optional. If it is not provided, the slider values will be placed as labels. If provided, the value of the tickmark labels and accessibility attributes (aria-valuenow and aria-valuetext) of the slider are changed accordingly.

Parameters

fValue

number

Value represented by the tickmark

oSlider

Slider | RangeSlider

Slider control that asks for a label

Returns

string | number

The label that should be placed in the current position.
