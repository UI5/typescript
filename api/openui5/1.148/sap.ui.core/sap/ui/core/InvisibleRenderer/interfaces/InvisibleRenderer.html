render()

render(oRm?, oElement?, sTagName?): void

Renders an invisible placeholder to identify the location of the invisible control within the DOM tree.

The standard implementation renders an invisible element for controls with visible:false to improve re-rendering performance. Due to the fault tolerance of the HTML5 standard, such elements are accepted in many scenarios and won't appear in the render tree of the browser. However, in some cases, controls might need to write a different element if is not an allowed element (for example, within the or group). In this case, the caller can require this module and use the third parameter to define the HTML tag.
