Type Alias: CSSColor

import { CSSColor } from "sap/ui/core/library";

CSSColor = string

A string type that represents CSS color values (CSS Color Level 3).

Allowed values are: - Hex colors like #666666 or #fff, - HSL/RGB values with or without transparency, like hsla(90,10%,30%,0.5) or rgb(0,0,0), - CSS color names like darkblue, or special values like inherit and transparent, - an empty string, which has the same effect as setting no color. For more information about the CSS Level 3 color specification, see https://www.w3.org/TR/css-color-3/#css-system.
