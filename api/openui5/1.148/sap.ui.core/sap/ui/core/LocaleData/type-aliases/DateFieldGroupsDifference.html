Type Alias: DateFieldGroupsDifference

import { DateFieldGroupsDifference } from "sap/ui/core/LocaleData";

DateFieldGroupsDifference = object

Type which describes the difference in the date field groups of the two dates of an date time interval. The keys are the names of the date field symbol groups. If one of them is set, the value should be set to true.
