Class: FileSizeFormat

import FileSizeFormat from "sap/ui/core/format/FileSizeFormat";

The FileSizeFormat is a static class for formatting and parsing numeric file size values according to a set of format options.

Supports the same options as sap.ui.core.format.NumberFormat.getFloatInstance NumberFormat.getFloatInstance For format options which are not specified default values according to the type and locale settings are used.

Supported format options (additional to NumberFormat): - binaryFilesize: Whether to use base 2, that means 1 Kibibyte = 1024 Byte, or base 10, that means 1 Kilobyte = 1000 Byte
