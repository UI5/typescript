Class: TemplateControl

import TemplateControl from "sap/ui/core/tmpl/TemplateControl";

This is the base class for all template controls. Template controls are declared based on templates.

Since

1.15

Deprecated

As of version 1.56. Use an sap.ui.core.mvc.XMLView XMLView or a topic:e6bb33d076dc4f23be50c082c271b9f0 Typed View instead.

getContext()

getContext(): object

Gets current value of property #getContext context.

The context is a data object. It can be used for default template expressions. A change of the context object leads to a re-rendering whereas a change of a nested property of the context object doesn't. By default the context is an empty object.

setContext(oContext?): this

Sets a new value for property #getContext context.

The context is a data object. It can be used for default template expressions. A change of the context object leads to a re-rendering whereas a change of a nested property of the context object doesn't. By default the context is an empty object.

When called with a value of null or undefined, the default value of the property will be restored.
