filter()

filter(aFilters?, sFilterType?, bReturnSuccess?): this

Applies the given filters to the ODataTreeBinding.

Please note that filters of type FilterType.Control are not supported for OperationMode.Server, here only filters of type FilterType.Application are allowed. Filters given via sap.ui.model.odata.v2.ODataModel#bindTree are always of type Application and will be sent with every back-end request. For more information, see sap.ui.model.odata.v2.ODataModel#bindTree.

Since 1.34.0, complete client-side filtering is supported for OperationMode.Client and also in OperationMode.Auto if the back-end count is lower than the threshold. In this case, all types of filters will be applied on the client. See also: sap.ui.model.odata.OperationMode.Auto and sap.ui.model.FilterType.

For the OperationMode.Client and OperationMode.Auto, you may also specify the useServersideApplicationFilters binding parameter when creating an instance. If it is set, the filters of type Application will always be applied on the back end and trigger an OData request. For more information, see sap.ui.model.odata.v2.ODataModel#bindTree. Note: sap.ui.model.odata.OperationMode.Auto is deprecated since 1.102.0. See: sap.ui.model.TreeBinding.prototype.filter

Parameters

aFilters?

Filter | Filter[]

The filters to use; in case of type sap.ui.model.FilterType.Application this replaces the filters given in sap.ui.model.odata.v2.ODataModel#bindTree; a falsy value is treated as an empty array and thus removes all filters of the specified type

sFilterType?

"Application" | FilterType | "ApplicationBound" | "Control"

The type of the filter to replace

bReturnSuccess?

boolean

Whether to return true or false, instead of this, depending on whether the filtering has been done

getRootContexts()

getRootContexts(iStartIndex?, iLength?, iThreshold?): Context1[]

Returns root contexts for the tree. You can specify the start index and the length for paging requests. This function is not available when the annotation "hierarchy-node-descendant-count-for" is exposed on the service.

Parameters

iStartIndex?

number

The start index of the requested contexts

iLength?

number

The requested amount of contexts. If none given, the default value is the size limit of the underlying sap.ui.model.odata.v2.ODataModel instance.

iThreshold?

number

The number of entities which should be retrieved in addition to the given length. A higher threshold reduces the number of backend requests, yet these request blow up in size, since more data is loaded.
