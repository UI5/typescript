Class: Double

import Double from "sap/ui/model/odata/type/Double";

This class represents the OData primitive type Edm.Double, see type definition for OData V4.01 or type definition for OData V2.

In both sap.ui.model.odata.v2.ODataModel and sap.ui.model.odata.v4.ODataModel this type is represented as a number.
