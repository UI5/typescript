Type Declaration

check?

optional check?: (p1) => boolean

Will get invoked in every polling interval. If it returns true, the check is successful and the polling will stop. The first parameter passed into the function is the same value that gets passed to the success function. Returning something other than boolean in check will not change the first parameter of success.

success?

optional success?: (p1) => void

Will get invoked if the following conditions are met: - A control was found using viewName and Id that maches any addiotnally specified criteria e.g. controlType, matchers. If visible is true (it is by default), the control also needs to be rendered. - The check function returned true, or there is no check function
