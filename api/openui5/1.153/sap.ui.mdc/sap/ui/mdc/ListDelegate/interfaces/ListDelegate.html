getFilterDelegate()

getFilterDelegate(): FilterDelegateObject

Returns the filter delegate of the list that provides basic filter functionality, such as adding filter fields.

Application delegates must override this method and return an object with a working addItem implementation to enable the inbuilt filter personalization panel. The default implementation returns null from addItem, which means the filter panel is available but no filter fields are created unless overridden.

FilterDelegateObject
