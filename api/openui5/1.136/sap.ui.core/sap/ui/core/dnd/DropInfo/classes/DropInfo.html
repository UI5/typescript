Class: DropInfo

import DropInfo from "sap/ui/core/dnd/DropInfo";

Provides the configuration for drop operations. Note: This configuration might be ignored due to control sap.ui.core.Element.extend metadata restrictions.

getTargetAggregation(): string

Gets current value of property #getTargetAggregation targetAggregation.
