Class: FieldHelpUtil

import FieldHelpUtil from "sap/ui/core/fieldhelp/FieldHelpUtil";

Utility class to set field help information for controls for which field help information cannot be deduced automatically from OData metadata or for which the automatically deduced field help needs to be overwritten. These can be controls like filter fields that don't have OData property bindings.

Since

1.133.0

Methods

setDocumentationRef()

static setDocumentationRef(oElement, vDocumentationRefs): void

Sets the field help information for the given element as sap-ui-DocumentationRef custom data. Note that field help inferred from data bindings of control properties is overwritten by this method unless an empty array is given in parameter vDocumentationRefs.

Parameters

oElement

UI5Element

The element on which to set the field help

vDocumentationRefs

string | string[]

The string value or an array of string values of com.sap.vocabularies.Common.v1.DocumentationRef OData annotations, for example "urn:sap-com:documentation:key?=type=DE&id=MY_ID&origin=MY_ORIGIN""

void
