Interface: $CarouselSettings

import { $CarouselSettings } from "sap/ui/webc/main/Carousel";

Experimental

Describes the settings that can be provided to the Carousel constructor.

Deprecated

Defines the position of arrows.

Available options are: - Content - the arrows are placed on the sides of the current page. - Navigation - the arrows are placed on the sides of the page indicator.

hideNavigationArrows?

optional hideNavigationArrows?: boolean | PropertyBindingInfo | `{${string}}`

Experimental

Defines the visibility of the navigation arrows. If set to true the navigation arrows will be hidden.

Note: The navigation arrows are never displayed on touch devices. In this case, the user can swipe to navigate through the items.

hidePageIndicator?

Experimental

Defines the style of the page indicator. Available options are: - Default - The page indicator will be visualized as dots if there are fewer than 9 pages. If there are more pages, the page indicator will switch to displaying the current page and the total number of pages. (e.g. X of Y) - Numeric - The page indicator will display the current page and the total number of pages. (e.g. X of Y)
