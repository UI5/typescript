Interface: $IconSettings

import { $IconSettings } from "sap/ui/webc/main/Icon";

Experimental

Describes the settings that can be provided to the Icon constructor.

Deprecated

As of version 1.120. this Web Components consumption model has been discarded. Until an alternative Web Components consumption model is available in the future, use sap.m and sap.f controls with similar functionality. As of version 1.92.0. This control is experimental and its API might change significantly.

name?

optional name?: string | PropertyBindingInfo

Experimental

Defines the unique identifier (icon name) of the component.

To browse all available icons, see the demo:sap/m/demokit/iconExplorer/webapp/index.html SAP Icons, demo:sap/m/demokit/iconExplorer/webapp/index.html#/overview/SAP-icons-TNT SAP Fiori Tools and demo:sap/m/demokit/iconExplorer/webapp/index.html SAP Business Suite collections.

Example: name='add', name='delete', name='employee'.

Note: To use the SAP Fiori Tools icons, you need to set the tnt prefix in front of the icon's name.

Example: name='tnt/antenna', name='tnt/actor', name='tnt/api'.

Note: To use the SAP Business Suite icons, you need to set the business-suite prefix in front of the icon's name.

Example: name='business-suite/3d', name='business-suite/1x2-grid-layout', name='business-suite/4x4-grid-layout'.
