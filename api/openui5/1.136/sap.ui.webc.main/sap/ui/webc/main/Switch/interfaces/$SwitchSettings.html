Interface: $SwitchSettings

import { $SwitchSettings } from "sap/ui/webc/main/Switch";

Experimental

Describes the settings that can be provided to the Switch constructor.

Deprecated

As of version 1.120. this Web Components consumption model has been discarded. Until an alternative Web Components consumption model is available in the future, use sap.m and sap.f controls with similar functionality. As of version 1.92.0. This control is experimental and its API might change significantly.

Experimental

Determines the name with which the component will be submitted in an HTML form.

Note: When set, a native input HTML element will be created inside the component so that it can be submitted as part of an HTML form. Do not use this property unless you need to submit a form.
