Class: AvatarGroupItem

import AvatarGroupItem from "sap/f/AvatarGroupItem";

Represents a single avatar item displayed in the sap.f.AvatarGroup control.

Overview: The AvatarGroupItem control allows you to define additional properties that are applied when rendering each AvatarGroupItem instance in the sap.f.AvatarGroup control.
