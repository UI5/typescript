defaultIndent?

optional defaultIndent?: string | PropertyBindingInfo

Optional. Defines default for the whole Grid numbers of empty columns before the current span begins. It can be defined for large, medium and small screens. Allowed values are separated by space with case insensitive Letters XL, L, M or S followed by number of columns from 0 to 11 that the container has to take, for example, L2 M4 S6, M11, s10 or l4 m4.

Note: The parameters must be provided in the order .

defaultSpan?

optional defaultSpan?: string | PropertyBindingInfo

Optional. A string type that represents the span values of the Grid for large, medium and small screens. Allowed values are separated by space with case insensitive Letters XL, L, M or S followed by number of columns from 1 to 12 that the container has to take, for example, L2 M4 S6, M12, s10 or l4 m4.

Note: The parameters must be provided in the order .

hSpacing?

optional hSpacing?: number | PropertyBindingInfo | `{${string}}`

Optional. Defines the horizontal spacing between the content in the Grid. In rem, allowed values are 0, 0.5 , 1 or 2.

position?

optional position?: PropertyBindingInfo | `{${string}}` | "Left" | "Right" | "Center" | GridPosition

Optional. Defines the position of the Grid in the window or surrounding container.

vSpacing?

optional vSpacing?: number | PropertyBindingInfo | `{${string}}`

Optional. Defines the vertical spacing between the rows in the Grid. In rem, allowed values are 0, 0.5, 1 and 2.

width?

optional width?: string | PropertyBindingInfo

Optional. Defines the width of the Grid. If not specified, then 100%.
