Type Alias: ConditionObject

import { ConditionObject } from "sap/ui/mdc/condition/Condition";

ConditionObject = object

Condition object type defining the structure of a condition.

Properties

inParameters?

optional inParameters?: object

In parameters of the condition. For each field path, a value is stored. (It is obsolete and only filled for conditions stored on old user-variants.)

isEmpty?

optional isEmpty?: boolean

If set, the condition is empty (used as initially empty condition in sap.ui.mdc.valuehelp.content.Conditions Conditions)

operator

operator: string

Operator of the condition. The standard operators can are mentioned in sap.ui.mdc.enums.OperatorName OperatorName.

outParameters?

optional outParameters?: object

Out parameters of the condition. For each field path, a value is stored. (It is obsolete and only filled for conditions stored on old user-variants.)

payload?

optional payload?: object

Payload of the condition. Set by application. Data needs to be stringified. (as stored and loaded in variants)

validated

validated: ConditionValidated | keyof typeof ConditionValidated

If set to ConditionValidated.Validated, the condition is validated (by the value help) and not shown in the sap.ui.mdc.valuehelp.content.Conditions Conditions content

values

values: any[]

Array of values of the condition. Depending on the operator, this contains one or more entries. The entries are stored in an internal format regarding the used data type.
