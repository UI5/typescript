Class: MultiValueField

import MultiValueField from "sap/ui/mdc/MultiValueField";

A MultiValueField control can hold multiple values. The values are stored as items. A MultiValueField control can be used to bind its items to data of a certain data type. Based on the data type settings, a default control is rendered by the MultiValueField control as follows:

 - In display mode, usually a sap.m.Tokenizer Tokenizer control is rendered.
 - If `multipleLines` is set, an sap.m.ExpandableText ExpandableText control is rendered.
 - In edit mode, usually a sap.m.MultiInput MultiInput control is rendered.
 - If `multipleLines` is set, a sap.m.TextArea TextArea control is rendered.

### getItems()

> **getItems**(): [`MultiValueFieldItem`](../../field/MultiValueFieldItem/classes/MultiValueFieldItem.html)[]

Gets content of aggregation #getItems items.

Items of the `MultiValueField` control.

The items are not updated by user input or value help selection automatically. That's because an aggregation
binding can only be updated by the model, not by the bound aggregation. Therefore, the module:sap/ui/mdc/field/MultiValueFieldDelegate.updateItems MultiValueFieldDelegate.updateItems
function needs to be implemented to update the items after a user interaction.
