### items?

> `optional` **items?**: `` `{${string}}` `` \| [`AggregationBindingInfo`](../../../../../../sap.ui.core/sap/ui/base/ManagedObject/type-aliases/AggregationBindingInfo.html) \| [`MultiValueFieldItem`](../../field/MultiValueFieldItem/classes/MultiValueFieldItem.html) \| [`MultiValueFieldItem`](../../field/MultiValueFieldItem/classes/MultiValueFieldItem.html)[]

Items of the `MultiValueField` control.

The items are not updated by user input or value help selection automatically. That's because an aggregation
binding can only be updated by the model, not by the bound aggregation. Therefore, the module:sap/ui/mdc/field/MultiValueFieldDelegate.updateItems MultiValueFieldDelegate.updateItems
function needs to be implemented to update the items after a user interaction.
