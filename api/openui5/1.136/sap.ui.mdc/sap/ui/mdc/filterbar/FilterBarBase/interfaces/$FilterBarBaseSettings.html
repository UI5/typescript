### liveMode?

> `optional` **liveMode?**: `boolean` \| [`PropertyBindingInfo`](../../../../../../../sap.ui.core/sap/ui/base/ManagedObject/type-aliases/PropertyBindingInfo.html) \| `` `{${string}}` ``

Triggers a search automatically after a filter value has been changed.
 **Note:** The `liveMode` property only operates in non-mobile scenarios.
