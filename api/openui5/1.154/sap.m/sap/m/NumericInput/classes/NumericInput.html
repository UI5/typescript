attachChange()

Call Signature

attachChange(oData, fnFunction, oListener?): this

Experimental

Attaches event handler fnFunction to the #event:change change event of this sap.m.NumericInput.

When called, the context of the event handler (its this) will be bound to oListener if specified, otherwise it will be bound to this sap.m.NumericInput itself.

Fired when one of the following happens:

 - The text in the input has changed and the focus leaves the input field or the enter key is pressed.

 - One of the decrement or increment buttons is pressed
Parameters

object
